# Odometry

- 로봇이나 차량이 자신의 시작 위치로부터 현재 위치까지 얼마나 이동했느지 추적하는 데 사용

- 주로 로봇의 위치 추정 및 탐색 시스템에서 사용되며, SLAM과 같은 더 복잡한 탐색 알고리즘에서 중요한 초석 역할을 함.

- 오도메트리는 센서의 누적 오차와 환경적 요인에 의해 error가 증가할 수 있기 때문에, 보다 정확한 위치 추정을 위해 SLAM과 같은 기술과 함께 사용되거나, 추가적인 센서 정보로 보정되는 경우가 많음.
    - Wheel Odometry, LiDAR Odometry, Visual Odometry, Wheel Inertial Odometry, LiDAR Inertial Odometry, Visual Inertial Odometry, GNSS Odometry

- 상용화된 대부분의 모바일 로봇에서는 encorder, IMU와 같은 센서를 융합하여 시산에 따른 로봇의 위치 및 방향(포즈)을 추정

-> 이 추정 결과는 SLAM 및 Navigation에서 모두 중요하게 사용


# 왜 Odometry가 자율주행에 있어 중요한 정보인가?
Mapping, Localization, Navigation, Feedback Control

# 모바일 로봇에서 2D LiDAR가 주로 사용되는 이유
## Wheel Odometry의 단점
- 휠 슬립(wheel slip)
- 주행에 따른 오차 누적
- 바퀴의 변형

## 그럼 2D LiDAR 단독으로 2D LiDAR Odometry를 사용하면?
- 특징이 부족한 환경
- Drift 문제
- 동적 환경에서의 문제

# 2D LiDAR 기반 알고리즘의 핵심
## ICP(Iterative Closest Point)
- 두 포인트 클라우드 간의 정렬을 최적화하여, 로봇이나 센서의 위치를 정밀하게 추정하는 방법

- 아래 세 가지 주요 단계를 반복적으로 수행
    1) Association
    2) Transformation
    3) Error Evaluation

- 입력
    - 소스 포인트 클라우드, 타겟 포인트 클라우드, 초기 추정치(선택적)

- 출력
    - 최적의 변호나 행렬(Transformation Matrix), 정합 오차(Registration Error)
