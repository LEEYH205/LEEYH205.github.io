#
- `speed_covert`: 입력된 속도(m/s)를 바퀴의 회전 속도(rps)로 변환
    
    ```python
    def speed_covert(self, speed):
        return speed / (math.pi * self.wheel_diameter)
    ```
    - 단위 시간(1초) 동안 바퀴가 몇 번 돌았는지 계산하기 위해, 속도를 바퀴의 회전수로 변환
    
    $$

        C = π × D = 2\pi × r
    $$
    → $C$: 바퀴 둘레
    
    → $D$: 바퀴 직경
    
    → $r$: 바퀴 반지름

    $$
    RPS=\frac{V}{\pi \times D}=\frac{V}{2\pi \times r}=\frac{V}{C}
    $$

# Ackermann Steering 구현

```python
def set_velocity(self, linear_speed, angular_speed, reset_servo=True):
    servo_angle = 1500
    data = []
    if abs(linear_speed) >= 1e-8:
        if abs(angular_speed) >= 1e-8:
            theta = math.atan(self.wheelbase*angular_speed/linear_speed)
            steering_angle = theta
            if abs(steering_angle) > math.radians(45):
                steering_angle = math.radians(45)
            servo_angle = 1500 + 2000*math.degrees(steering_angle)/180

        vr = linear_speed + angular_speed*self.track_width/2
        vl = linear_speed - angular_speed*self.track_width/2
        v_s = [self.speed_covert(v) for v in [0, vl, 0, -vr]] # [v1(왼/앞), v2(왼/뒤), v3(오/앞), v4(오/뒤)]
        for i in range(len(v_s)):
            msg = MotorState()
            msg.id = i + 1
            msg.rps = float(v_s[i])
            data.append(msg) 
        msg = MotorsState()
        msg.data = data
        return servo_angle, msg
    else:
        for i in range(4):
            msg = MotorState()
            msg.id = i + 1
            msg.rps = 0.0
            data.append(msg)
        msg = MotorsState()
        msg.data = data
        return None, msg
```
- `set_velocity`: 선속도·각속도를 각 바퀴 RPS로 변환
    1. 선속도(linear_speed)와 각속도(angular_speed) 입력
    2. Ackermann 모델로 조향각 계산 (atan 공식)
    3. 각도 제한 후 서보 PWM 값으로 변환 (중앙 PWM: 1500)
    4. 좌우 바퀴 속도(vl, vr) 계산
    5. RPS 단위 변환 → MotorsState 메시지 생성
    6. 선속도가 0에 가까울 때는 모든 모터 정지

## **각속도 일관성 (Consistency of Angular Velocity)**

$$\omega=\frac{V}{R}=\frac{V_L}{R_L}=\frac{V_R}{R_R}$$
- 모든 바퀴는 동일한 각속도(ω)를 가져야 함
- 변수 정의
    - $\omega$: 차량의 각속도 (rad/s)
    - $R$: 차량의 회전 반경 (m)
    - $V$: 차량의 선속도 (m/s)
    - $V_L$: 왼쪽 후륜 속도
    - $V_R$: 오른쪽 후륜 속도
    - $R_L$: 왼쪽 바퀴 회전 반경
    - $R_R$: 오른쪽 바퀴 회전 반경

## **전륜 조향각과 차량 회전 반경의 관계**

$$
\tan \theta=\frac{H}{R} \quad, \quad R_L=R-\frac{D}{2} \quad, \quad R_R=R+\frac{D}{2}$$
- 변수 정의
    - $H$: 차량의 축간 거리 (Wheelbase)
    - $D$: 차량의 윤거 (Track Width)
    - $R$: 차량의 회전 반경
    - $\theta$: 전륜 조향각

## **로봇 좌/우 바퀴 속도 계산**

- 전체 속도 $V$와 각속도 $\omega$가 주어졌을 때
    
    $$
    
    V_L = \omega \cdot \left(R - \frac{D}{2}\right), \quad V_R = \omega \cdot \left(R + \frac{D}{2}\right)
    
    $$
    
- 즉, 내륜(왼쪽 바퀴)은 더 작은 회전 반경을 가지므로 속도가 더 느리고, 외륜(오른쪽 바퀴)은 더 큰 회전 반경을 가지므로 속도가 더 빠름


### **서보 조향각 기반 속도 산출**

- 알고 있는 값
    - $H$: 차량의 축간 거리 (Wheelbase)
    - $D$: 차량의 윤거 (Track Width)
    - $V$: 차량 선속도
    - $\theta$: 전륜 조향각, 서보에 의해 결정
- 계산 절차
    1. 조향각 θ로부터 차량의 회전 반경 R 계산
        
        $$
        R = \frac{H}{\tan(\theta)}
        $$
        
    2. 내/외륜 회전 반경 산출
        
        $$
        R_L = R - \frac{D}{2}, \quad R_R = R + \frac{D}{2}
        $$
        
    3. 좌/우 바퀴 속도 계산
        
        $$
        V_L = V \cdot \frac{R_L}{R}, \quad V_R = V \cdot \frac{R_R}{R}
        $$
