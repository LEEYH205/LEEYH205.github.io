# IMU (**Inertial Measurement Units)**

---

## 개요


- **Linear accelerator (선형가속도 측정) 와 Angular gyroscope (각속도 측정)를 포함하는 센서**
    - [Spring-damper system](https://en.wikipedia.org/wiki/Mass-spring-damper_model)의 원리를 이용하여 만든 시스템
- **장점**
    - 저렴한 consumer grade 제품 존재
    - 높은 sensitivity와 샘플링 주기 (100Hz, 200Hz, 400Hz, 800Hz 등)
- **단점**
    - 시간이 지남에 따라 bias에 의한 drift가 생김
    - 높은 정확도 + 낮은 drift를 가진 tactical grade IMU는 금액이 높음

# MentorPi에서 사용되는 부분
## MCU
 - QMI8658


 - I2C 통신 함수 (`QMI8658.c`)
    
    ```c
    /**
     * @brief 레지스터에 값 쓰기
     * @param reg 레지스터 주소
     * @param value 쓸 값
     */
    void write_reg(uint8_t reg, uint8_t value)
    {
        IIC_WriteToMem(QMI8658_ADDR << 1, reg, &value, 1);
    }
    
    /**
     * @brief 레지스터에서 값 읽기
     * @param reg 레지스터 주소
     * @return 읽은 값
     */
    uint8_t read_reg(uint8_t reg)
    {
        uint8_t ret = 0;
        IIC_ReadFromMem(QMI8658_ADDR << 1, reg, &ret, 1);
        return ret;
    }
    
    /**
     * @brief 레지스터에서 16bit 값 읽기 (Little Endian)
     * @param reg 레지스터 주소 (Low byte)
     * @return 읽은 16bit 값
     */
    uint16_t readWord_reg(uint8_t reg)
    {
        uint8_t ret[2] = {0, 0};
        IIC_ReadFromMem(QMI8658_ADDR << 1, reg, ret, 2);
        return ((ret[1] << 8) | ret[0]);  // High byte << 8 | Low byte
    }
    ```
    
- 센서 데이터 읽기 (`QMI8658.c`)
    
    ```c
    /**
     * @brief Accelerometer와 Gyroscope 원시 데이터 읽기 및 물리량 변환
     * @param acc[3] 출력: 가속도 값 (g 또는 m/s²)
     * @param gyro[3] 출력: 각속도 값 (dps 또는 rad/s)
     */
    void read_sensor_data(float acc[3], float gyro[3])
    {
        short raw_acc_xyz[3];
        short raw_gyro_xyz[3];
    
        // Accelerometer 원시 데이터 읽기 (16bit, signed)
        raw_acc_xyz[0] = (short)((unsigned short)(readWord_reg(Qmi8658Register_Ax_L)));
        raw_acc_xyz[1] = (short)((unsigned short)(readWord_reg(Qmi8658Register_Ay_L)));
        raw_acc_xyz[2] = (short)((unsigned short)(readWord_reg(Qmi8658Register_Az_L)));
    
        // Gyroscope 원시 데이터 읽기 (16bit, signed)
        raw_gyro_xyz[0] = (short)((unsigned short)(readWord_reg(Qmi8658Register_Gx_L)));
        raw_gyro_xyz[1] = (short)((unsigned short)(readWord_reg(Qmi8658Register_Gy_L)));
        raw_gyro_xyz[2] = (short)((unsigned short)(readWord_reg(Qmi8658Register_Gz_L)));
    
        // 원시 값을 물리량으로 변환 (scale factor로 나누기)
        // ssvt_a: accelerometer scale value, ssvt_g: gyroscope scale value
        acc[0] = (float)(raw_acc_xyz[0] * 1.0f) / g_imu.ssvt_a;
        acc[1] = (float)(raw_acc_xyz[1] * 1.0f) / g_imu.ssvt_a;
        acc[2] = (float)(raw_acc_xyz[2] * 1.0f) / g_imu.ssvt_a;
    
        gyro[0] = (float)(raw_gyro_xyz[0] * 1.0f) / g_imu.ssvt_g;
        gyro[1] = (float)(raw_gyro_xyz[1] * 1.0f) / g_imu.ssvt_g;
        gyro[2] = (float)(raw_gyro_xyz[2] * 1.0f) / g_imu.ssvt_g;
    }
    
    /**
     * @brief IMU 데이터 읽기 (상태 확인 후 읽기)
     * @param acc[3] 출력: 가속도 값
     * @param gyro[3] 출력: 각속도 값
     */
    void read_xyz(float acc[3], float gyro[3])
    {
        unsigned char status;
        unsigned char data_ready = 0;
    
        // 데이터 준비 상태 확인
        status = read_reg(Qmi8658Register_Status0);
        if(status & 0x03)  // Accelerometer와 Gyroscope 데이터 준비
        {
            data_ready = 1;
        }
    
        if(data_ready)
        {
            read_sensor_data(acc, gyro);      // 센서 데이터 읽기
            axis_convert(acc, gyro, 0);      // 축 변환 (설치 방향에 맞게)
            
            // 전역 변수에 저장
            g_imu.imu[0] = acc[0];
            g_imu.imu[1] = acc[1];
            g_imu.imu[2] = acc[2];
            g_imu.imu[3] = gyro[0];
            g_imu.imu[4] = gyro[1];
            g_imu.imu[5] = gyro[2];
        }
        else
        {
            // 데이터가 준비되지 않았으면 이전 값 사용
            acc[0] = g_imu.imu[0];
            acc[1] = g_imu.imu[1];
            acc[2] = g_imu.imu[2];
            gyro[0] = g_imu.imu[3];
            gyro[1] = g_imu.imu[4];
            gyro[2] = g_imu.imu[5];
        }
    }
    ```
    
- 처리 (`imu_porting.c`)
    
    ```c
    void imu_task_entry(void *argument)
    {
        // IMU 초기화
        if(begin() == 0)
        {
            // 초기화 실패 처리
        }
    
        PacketReportIMU_Raw_TypeDef report;
        for(;;) {
            // 센서 데이터 읽기
            read_xyz(report.array.accel_array, report.array.gyro_array);
            
            // 라즈베리파이로 데이터 전송
            packet_transmit(&packet_controller, PACKET_FUNC_IMU, &report, sizeof(PacketReportIMU_Raw_TypeDef));
            osDelay(20);
        }
    }
    ```

### IMU 데이터 처리

1. IMU 데이터 읽기 (MCU에서 데이터 수신) (`driver/ros_robot_controller/ros_robot_controller/ros_robot_controller_sdk.py`)
    
    ```python
    def get_imu(self):
        # 获取IMU数据，返回ax, ay, az, gx, gy, gz(obtain IMU data to return ax, ay, az, gx, gy, and gz)
        if self.enable_recv:
            try:
                # ax, ay, az, gx, gy, gz
                return struct.unpack('<6f', self.imu_queue.get(block=False))
            except queue.Empty:
                return None
        else:
            print('get_imu enable reception first!')
            return None
    ```
    
2. IMU 데이터 처리 및 변환 (가속도/각속도 변환) (`driver/ros_robot_controller/ros_robot_controller/ros_robot_controller_node.py`)
    
    ```python
    def pub_imu_data(self, pub):
        data = self.board.get_imu()
        if data is not None:
            ax, ay, az, gx, gy, gz = data
            msg = Imu()
            msg.header.frame_id = self.IMU_FRAME
            msg.header.stamp = self.clock.now().to_msg()
    
            msg.orientation.w = 0.0
            msg.orientation.x = 0.0
            msg.orientation.y = 0.0
            msg.orientation.z = 0.0
    
            msg.linear_acceleration.x = ax * self.gravity
            msg.linear_acceleration.y = ay * self.gravity
            msg.linear_acceleration.z = az * self.gravity
    
            msg.angular_velocity.x = math.radians(gx)
            msg.angular_velocity.y = math.radians(gy)
            msg.angular_velocity.z = math.radians(gz)
    
            msg.orientation_covariance = [0.01, 0.0, 0.0,
                                          0.0, 0.01, 0.0,
                                          0.0, 0.0, 0.01]
            msg.angular_velocity_covariance = [0.01, 0.0, 0.0,
                                              0.0, 0.01, 0.0,
                                              0.0, 0.0, 0.01]
            msg.linear_acceleration_covariance = [0.0004, 0.0, 0.0,
                                                 0.0, 0.0004, 0.0,
                                                 0.0, 0.0, 0.004]
            pub.publish(msg)
    ```

### IMU 보정 및 필터링 (센서 전처리)

- `peripherals/launch/imu_filter.launch.py`
    - IMU 처리 파이프라인
        - imu_raw → imu_calib (보정) → imu_corrected → imu_filter (complementary filter) → 최종 imu 값
    
    ```python
    imu_calib_node = Node(
        package='imu_calib',
        executable='apply_calib',
        name='imu_calib',
        output='screen',
        parameters=[{"calib_file": calib_file_path}],
        remappings=[
            ('raw', '/ros_robot_controller/imu_raw'),
            ('corrected', 'imu_corrected')
        ]
    )
    
    imu_filter_node = Node(
        package='imu_complementary_filter',
        executable='complementary_filter_node',
        name='imu_filter',
        output='screen',
        parameters=[
            {
                'use_mag': False,
                'do_bias_estimation': True,
                'do_adaptive_gain': True,
                'publish_debug_topics': True
            }
        ],
        remappings=[
            ('/tf', 'tf'),
            ('/imu/data_raw', 'imu_corrected'),
            ('imu/data', 'imu')
        ]
    )
    ```
    
    - **상보필터(Complementary Filter)**: 자이로스코프와 가속도계의 데이터를 서로 보완하여 더 정확한 자세(orientation)를 추정할 수 있도록 하는 필터링 기법
        - **자이로스코프**는 고주파(빠른 움직임) 영역에서는 정밀하지만, 시간이 지나면 드리프트(오차 누적)가 생기는 단점이 있음
        - **가속도계**는 저주파(느린 움직임, 정지상태) 영역에서는 비교적 정확하지만, 노이즈와 외란에 약한 단점이 있음
        - 상보필터는 자이로의 각속도를 적분해 얻은 각도와, 가속도계의 순간적인 각도를 서로 일정 비율로 가중해서, 자이로의 데이터에서 발생하는 오차를 가속도계 데이터로 보정하는 방식
