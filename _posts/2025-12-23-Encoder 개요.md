# Wheel Encoder

---

## 개요

- 바퀴의 회전량 (RPM)을 측정하는 센서
    - RPM * 바퀴 둘레 = 이동량
    - brush, optical, magentic, inductive, capacitative… 만드는 방법은 여러가지임
- 장점
    - 저렴한 가격
    - 최신 모터에는 기본적으로 탑재
- 단점
    - 3-DOF 모션만 추정 가능 ($x, y, yaw$)
    - 주행에 따른 오차 누적
        - 휠 슬립 (wheel slip), 바퀴의 변형

## JGA27-310R20
- AB 위상 출력 펄스 신호를 생성함으로써 모터 회전 방향 및 속도 감지
![](/assets/img/HiWonderPi/img/Incremental_Encoder_Shaft_Encoder_how_it_works.gif)
    - AB상 출력 신호는 90도 위상 차이를 가지므로 두 신호의 순서를 통해 모터의 회전 방향을 판별할 수 있음
    - 단위 시간 내 펄스 수와 타이어 둘레 정보를 이용하면 이동 거리 계산 가능
    - 단위 시간 내 AB상 펄스 수를 센다면 모터의 현재 속도도 산출 가능

## MCU

- Encoder 데이터 구조 (`encoder_motor.h`)
    
    ```c
    struct EncoderMotorObject{
        int64_t counter;        /**< @brief 총 카운터 값, 64bit로 overflow 방지 */
        int64_t overflow_num;   /**< @brief Overflow 카운트 */
        int32_t ticks_overflow; /**< @brief 카운터 overflow 값 */
        float tps;              /**< @brief ticks per second - 카운터 주파수 */
        float rps;              /**< @brief revolutions per second - 출력축 속도 (rps) */
    
        int32_t ticks_per_circle; /**< @brief 모터 출력축 1회전당 카운트 개수, 실제 모터 사양에 맞게 설정 */
    		...
    };
    ```
    
- Encoder 초기화 및 시작 (`motor_porting.c`)
    
    ```c
    /* Encoder 초기화 및 시작 */
    __HAL_TIM_SET_COUNTER(&htim5, 0);           // 카운터 0으로 초기화
    __HAL_TIM_CLEAR_IT(&htim5, TIM_IT_UPDATE);  // 인터럽트 플래그 클리어
    __HAL_TIM_ENABLE_IT(&htim5, TIM_IT_UPDATE); // Overflow 인터럽트 활성화
    __HAL_TIM_ENABLE(&htim5);                    // 타이머 활성화
    HAL_TIM_Encoder_Start(&htim5, TIM_CHANNEL_ALL); // Encoder 모드 시작
    ```
    
- Encoder 카운터 값을 속도로 변환 (`encoder_motor.c`)
    
    ```c
    /**
     * @brief Encoder motor 속도 측정 업데이트
     * @param self Encoder motor 객체 포인터
     * @param period 마지막 업데이트로부터의 시간 간격(업데이트 주기), 단위: sec
     * @param counter 현재 encoder 카운터 값
     */
    void encoder_update(EncoderMotorObjectTypeDef *self, float period, int64_t counter)
    {
        // Overflow 처리: 총 카운터 값 계산
        counter = counter + self->overflow_num * self->ticks_overflow;
        
        // 이전 값과의 차이 계산
        int delta_count = counter - self->counter;
        self->counter = counter; // 새로운 카운터 값 저장
        
        // Low-pass filter를 사용한 펄스 주파수 계산 (tps: ticks per second)
        self->tps = (float)delta_count / period * 0.9f + self->tps * 0.1f;
        
        // rps 계산: tps를 1회전당 카운트 수로 나누어 초당 회전수로 변환
        self->rps = self->tps / self->ticks_per_circle;
    }
    ```
    

## SBC

- 목표 바퀴 회전 속도 계산 (`driver/controller/controller/mecanum.py` or `ackermann.py`)
    
    ```python
    def speed_covert(self, speed):
          """
          covert speed m/s to rps/s
          :param speed:
          :return:
          """
          # distance / circumference = rotations per second
          return speed / (math.pi * self.wheel_diameter)
    ```
    
    ```python
    def set_velocity(self, linear_x, linear_y, angular_z):
    		...
    		
    	# mecanum
        motor1 = (linear_x - linear_y - angular_z * (self.wheelbase + self.track_width) / 2)
        motor2 = (linear_x + linear_y - angular_z * (self.wheelbase + self.track_width) / 2)
        motor3 = (linear_x + linear_y + angular_z * (self.wheelbase + self.track_width) / 2)
        motor4 = (linear_x - linear_y + angular_z * (self.wheelbase + self.track_width) / 2)
        v_s = [self.**speed_covert**(v) for v in [-motor1, -motor2, motor3, motor4]]
        
        # ackermann
        vr = linear_speed + angular_speed*self.track_width/2
        vl = linear_speed - angular_speed*self.track_width/2
        v_s = [self.**speed_covert**(v) for v in [0, vl, 0, -vr]]
        
        data = []
        for i in range(len(v_s)):
            msg = MotorState()
            msg.id = i + 1
            msg.rps = float(v_s[i])
            data.append(msg)
    
        msg = MotorsState()
        msg.data = data
        return msg
    ```
