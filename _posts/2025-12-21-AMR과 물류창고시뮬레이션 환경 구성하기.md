# 실습 환경 구성

---

## Neobotix


- Neobotix는 독일에 본사를 둔 로봇공학 회사로, 이동 로봇 플랫폼의 개발 및 제조를 전문으로 하고 있으며, 다양한 산업 및 연구 응용 분야를 위한 모듈식 이동 로봇 솔루션을 제공합니다.
- 주요 제품군에는 자율 이동 로봇(AMR)과 로봇 팔이 포함된 이동 로봇 플랫폼이 있습니다.


## 로봇 시뮬레이션 환경 구성 및 설치

1. 환경 구성을 위해 필요한 요소들을 설치합니다.
    
    ```bash
    sudo apt install ros-$ROS_DISTRO-navigation2 ros-$ROS_DISTRO-nav2-*
    ```
    
2. 워크스페이스 내에 필요한 리소스들을 가져옵니다.
    
    ```bash
    mkdir ~/nav2_ws/src/neobotix
    cd ~/nav2_ws/src/neobotix
    git clone https://github.com/neobotix/neo_msgs2.git
    git clone --branch $ROS_DISTRO https://github.com/neobotix/neo_local_planner2.git
    git clone --branch $ROS_DISTRO https://github.com/neobotix/neo_localization2.git
    git clone --branch $ROS_DISTRO https://github.com/neobotix/neo_nav2_bringup.git
    git clone --branch $ROS_DISTRO https://github.com/neobotix/neo_simulation2.git
    
    cd ~/nav2_ws/src/neobotix/neo_simulation2
    git checkout e2b39b7917b4becf69d5ece0a0129dc9188c309a
    ```
    
3. 워크스페이스 내 패키지들을 빌드합니다.
    
    ```bash
    cd ~/nav2_ws/
    colcon build --symlink-install --cmake-args -DCMAKE_BUILD_TYPE=Release
    
    source install/local_setup.bash # 환경에 따라 local_setup.zsh
    ```
    
4. `~/nav2_ws/src/neobotix/neo_simulation2/configs/mpo_700/navigation.yaml` 파일의 잘못된 AMCL 설정을 수정해줍니다.
    - 101번 째 줄 수정
        - 기존: `robot_model_type: "omnidirectional”`
        - 수정: `robot_model_type: "nav2_amcl::OmniMotionModel”`
        ```yaml
        amcl:
        ros__parameters:
	  
        ...
        
        **robot_model_type: "nav2_amcl::OmniMotionModel"**
        
        ...
        ```

- `mpo_700`은 (1) 자체 Localization 알고리즘과 (2) AMCL 중 선택할 수 있습니다.
5. `~/nav2_ws/src/neobotix/neo_simulation2/launch/simulation.launch.py` 파일에서 `aws.world`가 강제로 켜지도록 수정해줍니다.
    - 68번 째 줄 수정
        
        ```python
        # Get the required paths for the world and robot robot_description_urdf
        if (my_neo_environment == "neo_workshop" or my_neo_environment == "neo_track1"):
            world_path = os.path.join(
                get_package_share_directory('neo_simulation2'),
                'worlds',
                **'aws.world') # 수정 !!**
        ```
        
6. `~/nav2_ws/src/neobotix/neo_simulation2/launch/navigation.launch.py` 파일에서 지도 메타 파일인 `aws.yaml`를 강제로 불러오도록 수정해줍니다.
    - 61번 째 줄 수정
        
        ```python
        # Only set path for the neobotix supported maps
        if (my_neo_environment == "neo_workshop" or my_neo_environment == "neo_track1"):
            map_dir = os.path.join(
                    get_package_share_directory('neo_simulation2'),
                    'maps',
                    **'aws.yaml') # 수정 !!**
        ```
## 시뮬레이션 환경 열기 및 간단한 제어

1. 새 터미널을 열고 시뮬레이션 환경이 잘 열리는지 확인합니다.
    
    ```bash
    export MY_ROBOT=mpo_700
    ros2 launch neo_simulation2 simulation.launch.py
    ```

![](/assets/img/Screenshot%20from%202025-12-21%2011-19-29.png)

2. 아래 명령어를 통해 로봇을 제어해 볼 수 있습니다.
    
    ```bash
    ros2 run teleop_twist_keyboard teleop_twist_keyboard
    ```
    
    - Holonomic Driving을 지원하므로 `Shift` 버튼을 누른채로 움직이면, 조향 없이 이동할 수 있습니다.
    ![](/assets/img/Peek%202025-12-21%2011-21.gif)

3. nav2를 사용하기 위해 아래 런치파일을 실행시킵니다.
    
    ```bash
    ros2 launch neo_simulation2 navigation.launch.py
    ```
    
    - 1) 자체 Localization 알고리즘이 아닌 (2) AMCL을 사용하고 싶을 경우 아래와 같이 런치파일을 실행시킵니다.
        
        ```bash
        ros2 launch neo_simulation2 navigation.launch.py use_amcl:=True
        ```
        
4. Rviz2  실행을 위해 아래 런치파일을 실행시킵니다.
    
    ```bash
    ros2 launch neo_nav2_bringup rviz_launch.py
    ```
