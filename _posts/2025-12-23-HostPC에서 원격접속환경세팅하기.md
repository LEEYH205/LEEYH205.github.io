`/home/ubuntu/ros2_ws/src`에서 작업

![](/assets/img/HiWonderPi/img/Screenshot%20from%202025-12-23%2009-49-25.png)

현재 VSCode 상에서 터미널이 열릴 때 문제는 아래와 같습니다.
- 문제점
    - VSCode에 로봇의 Docker 환경을 attach시켰을 때, root 계정으로 시도함
    - 그렇다보니 `$HOME` 환경변수가 `/home/ubuntu`가 아닌 `/root`
- 해결 방법
    - `$HOME` 환경변수를 `/home/ubuntu`로 수정해야함
    - `/home/ubuntu/.zshrc` 를 source해야 ros2 환경이 정상적으로 열림
    - zsh이 켜질 때 `$HOME/.zshrc` 를 읽어오는 점을 활용하여, `/root/.zshrc`를 수정

`code ~/.zshrc` (`code /root/.zshrc`와 동일) 명령어로 창을 열고 아래와 같이 입력합니다.
    
```bash
    export HOME=/home/ubuntu
    source $HOME/.zshrc
```
