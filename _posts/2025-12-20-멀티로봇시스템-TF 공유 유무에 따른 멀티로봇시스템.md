## Turtlebot3

## 로봇 시뮬레이션 환경 구성 및 설치

1. 아래 파일을 다운로드받고 압축을 푼 뒤, `~/nav2_ws/src` 디렉토리 안으로 옮겨줍니다.

2. 워크스페이스 내 패키지들을 빌드합니다.
```BASH
cd ~/nav2_ws/
rosdep install --from-paths src/tb3_multi_sim/turtlebot3_multi_robot -y --ignore-src --os=ubuntu:jammy
colcon build --symlink-install --packages-select turtlebot3 turtlebot3_description turtlebot3_msgs turtlebot3_gazebo turtlebot3_multi_robot

source install/local_setup.bash # 환경에 따라 local_setup.zsh
```


## 로봇 시뮬레이션 환경 구성 및 설치

1. 새 터미널을 열고 시뮬레이션 환경이 잘 열리는지 확인합니다.
    
    ```bash
    # 2대의 turtlebot3를 spawn할 경우
    ros2 launch turtlebot3_gazebo turtlebot3_tc_world_two_robots.launch.py
    
    # 3대의 turtlebot3를 spawn할 경우
    ros2 launch turtlebot3_gazebo turtlebot3_tc_world_three_robots.launch.py
    ```

    # Topic
    ros2 topic list

## launch 파일

- `~/nav2_ws/src/tb3_multi_sim/turtlebot3_gazebo/launch/multi_localization_three.launch.py`
    
    ```python
    ...
    
    def generate_launch_description():
    
        tb3_0_config = os.path.join(get_package_share_directory('turtlebot3_gazebo'), 'config', 'tb3_0_amcl.yaml')
        tb3_1_config = os.path.join(get_package_share_directory('turtlebot3_gazebo'), 'config', 'tb3_1_amcl.yaml')
        tb3_2_config = os.path.join(get_package_share_directory('turtlebot3_gazebo'), 'config', 'tb3_2_amcl.yaml')
    
        map_file = os.path.join(get_package_share_directory('turtlebot3_gazebo'), 'map', 'turtlebot_area.yaml')
    
        return LaunchDescription([
            Node(
                package='nav2_map_server',
                executable='map_server',
                name='map_server',
                output='screen',
                parameters=[{'use_sim_time': True},
                            {'topic_name':"map"},
                            {'frame_id':"map"},
                            {'yaml_filename':map_file}]
            ),
    
            Node(
                namespace='**tb3_0**',
                package='nav2_amcl',
                executable='amcl',
                name='amcl',
                output='screen',
                parameters=[tb3_0_config]
            ),
    
            Node(
                namespace='**tb3_1**',
                package='nav2_amcl',
                executable='amcl',
                name='amcl',
                output='screen',
                parameters=[tb3_1_config]
            ),
    
            ...
    
            Node(
                package='nav2_lifecycle_manager',
                executable='lifecycle_manager',
                name='lifecycle_manager_localization',
                output='screen',
                parameters=[{'use_sim_time': True},
                            {'autostart': True},
                            {'bond_timeout':0.0},
                            **{'node_names': ['map_server', 'tb3_0/amcl', 'tb3_1/amcl', 'tb3_2/amcl']}]**
            ),
    
            ...
        ])
    ```

## rviz 파일
1. Multi-robot localization을 위한 런치 파일을 실행시킵니다.
    
    ```python
    ros2 launch turtlebot3_gazebo multi_localization_three.launch.py
    ```
![](/assets/img/Screenshot%20from%202025-12-20%2016-48-00.png)

2. 초기 위치를 수동으로 설정하고 싶을 경우, Tool Properties의 2D Pose Estimate에서 토픽 이름을 설정해주고 초기 위치를 변경
![](/assets/img/Peek%202025-12-20%2016-46.gif)

3. 각각의 로봇을 제어하면서 localization이 잘 수행되는지 확인합니다.
    
    ```bash
    # tb3_0 로봇 제어
    ros2 run teleop_twist_keyboard teleop_twist_keyboard --ros-args --remap cmd_vel:=/tb3_0/cmd_vel
    
    # tb3_1 로봇 제어
    ros2 run teleop_twist_keyboard teleop_twist_keyboard --ros-args --remap cmd_vel:=/tb3_1/cmd_vel
    
    # tb3_2 로봇 제어
    ros2 run teleop_twist_keyboard teleop_twist_keyboard --ros-args --remap cmd_vel:=/tb3_2/cmd_vel
    ```
