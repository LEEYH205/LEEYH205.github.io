# QR 코드 생성 및 인식

---

## 개요

> `qrcode` 라이브러리와 `pyzbar` 라이브러리를 활용하여 QR 코드를 생성하고, 카메라를 통해 실시간으로 QR 코드를 인식하는 프로젝트 입니다.
> 

**주요 구성**

- **QR 코드 생성**: `qrcode_creater.py` - 텍스트를 입력받아 QR 코드 이미지를 생성
- **QR 코드 인식**: `qrcode_detecter.py` - 카메라 이미지에서 QR 코드를 실시간으로 검출 및 디코딩

## 동작 원리

### QR 코드 생성 과정

1. **사용자 입력**: 텍스트 데이터를 입력
2. **QR 코드 객체 생성**: 버전, 오류 정정 레벨, 박스 크기, 테두리 크기 설정
3. **데이터 추가**: 입력받은 텍스트를 QR 코드에 추가
4. **QR 코드 생성**: 설정에 따라 QR 코드 이미지 생성
5. **이미지 변환**: PIL 이미지를 OpenCV 형식으로 변환
6. **화면 표시 및 저장**: 생성된 QR 코드를 화면에 표시하고 파일로 저장

### QR 코드 인식 과정

1. **이미지 수신**: ROS2를 통해 카메라 이미지를 구독
2. **QR 코드 검출**: `pyzbar` 라이브러리를 사용하여 이미지에서 QR 코드를 검출
3. **디코딩**: 검출된 QR 코드의 데이터를 디코딩
4. **시각화**: QR 코드 영역을 초록색 선으로 표시하고, 디코딩된 텍스트를 이미지에 표시
5. **결과 출력**: 콘솔에 디코딩된 데이터를 출력

## QR 코드 (Quick Response Code)

![](/assets/img/HiWonderPi/img/download/QRcode.png)

### **QR 코드란?**

> QR 코드는 1994년 일본의 덴소웨이브(Denso Wave)에서 개발한 2차원 바코드입니다. 빠른 응답(Quick Response)이 가능하도록 설계되었으며, 수평과 수직 방향 모두에서 데이터를 읽을 수 있습니다.
> 

### **QR 코드의 특징**

- **대용량 데이터 저장**: 최대 4,296자의 숫자 또는 2,953바이트의 바이너리 데이터 저장 가능
- **오류 정정 기능**: 일부가 손상되어도 데이터 복구 가능
- **빠른 인식**: 360도 어느 방향에서든 인식 가능
- **다양한 데이터 형식**: 텍스트, URL, 연락처 정보, 이메일 등 다양한 형식 지원

### pyzbar 라이브러리

> `pyzbar`는 Python용 바코드 및 QR 코드 스캐너 라이브러리입니다. ZBar 라이브러리의 Python 바인딩으로, 다양한 바코드 형식(QR 코드, Code128, EAN-13 등)을 인식할 수 있습니다.
> 
- QR 코드 및 바코드 검출
- 다중 코드 동시 인식
- 다양한 이미지 형식 지원 (PNG, JPEG 등)
- 코드 위치 정보 제공 (다각형 좌표)

**decode() 함수**

```python
decoded_objects = pyzbar.decode(image)
```

- 입력: 이미지 (numpy 배열 또는 PIL Image)
- 출력: 검출된 코드 객체 리스트
- 각 객체는 `data`, `type`, `rect`, `polygon` 등의 속성을 가짐
    - `data`: 디코딩된 데이터 (바이트 형식)
    - `type`: 코드 타입 (QRCODE, CODE128 등)
    - `rect`: 바운딩 박스 (left, top, width, height)
    - `polygon`: 코드의 다각형 좌표 (4개 이상의 점)


## Convex Hull (볼록 껍질)

### **Convex Hull이란?**

![](/assets/img/HiWonderPi/img/download/Convex%20Hull.png)

> 볼록 껍질은 주어진 점들의 집합을 모두 포함하는 가장 작은 볼록 다각형입니다. QR 코드 인식에서 4개 이상의 점이 검출된 경우, 볼록 껍질을 사용하여 QR 코드의 경계를 단순화합니다.
> 

**본 프로젝트에서 사용 이유**

- QR 코드는 정사각형이지만, 카메라 각도에 따라 사다리꼴이나 다른 형태로 보일 수 있음
- `pyzbar`가 4개 이상의 점을 반환할 수 있음
- Convex Hull을 사용하여 QR 코드의 외곽선을 정확하게 그릴 수 있음

**OpenCV 함수**

![](/assets/img/HiWonderPi/img/download/Convex%20Hull_1.png)

```python
hull = cv2.convexHull(points)
```

- 입력: 점들의 배열
- 출력: Convex Hull을 구성하는 점들

## 1. QR 코드 생성 프로그램

### **프로그램 시작 및 사용자 입력**

```python
if __name__ == '__main__':
    file_path = os.getcwd()  # 현재 작업 디렉토리 경로 가져오기
    out_img = file_path + '/myQRcode.jpg'  # 출력 이미지 파일 경로
    qrcode_text = input("Please enter：")  # 사용자로부터 텍스트 입력받기
```

### **QR 코드 생성 함수**

```python
def create_qrcode(data, file_name):
    # QR 코드 객체 생성
    qr = qrcode.QRCode(
        version=1,  # 버전 1 (21×21 셀)
        error_correction=qrcode.constants.ERROR_CORRECT_H,  # 높은 오류 정정 레벨 (약 30%)
        box_size=5,  # 각 셀당 5픽셀
        border=4)  # 테두리 4셀
    
    # 添加数据(add data)
    qr.add_data(data)  # 입력받은 데이터를 QR 코드에 추가
    
    # 填充数据(fill data)
    qr.make(fit=True)  # 데이터에 맞게 QR 코드 생성 (fit=True: 자동으로 버전 조정)
    
    # 生成图片(generate image)
    img = qr.make_image(fill_color=(0, 0, 0), back_color=(255, 255, 255))  # 검은색 QR 코드, 흰색 배경
    opencv_img = cv2.cvtColor(np.asarray(img), cv2.COLOR_RGB2BGR)  # PIL 이미지를 OpenCV 형식으로 변환 (RGB → BGR)
    
    # 화면에 표시 (아무 키나 누를 때까지 대기)
    while True:
        cv2.imshow('img', opencv_img)
        k = cv2.waitKey(1)
        if k != -1:  # 키 입력이 있으면 종료
            break
    
    # 이미지 파일로 저장
    cv2.imwrite(file_name, opencv_img)
    print('save', data, file_name)
```

- **처리 단계**
    1. **QR 코드 객체 생성**: 버전, 오류 정정 레벨, 박스 크기, 테두리 설정
    2. **데이터 추가**: `add_data()`로 텍스트 데이터 추가
    3. **QR 코드 생성**: `make(fit=True)`로 데이터에 맞게 QR 코드 생성
    4. **이미지 생성**: `make_image()`로 PIL 이미지 생성
    5. **형식 변환**: PIL 이미지를 OpenCV 형식(BGR)으로 변환
    6. **화면 표시**: OpenCV 창에 표시하고 키 입력 대기
    7. **파일 저장**: 생성된 QR 코드를 JPEG 파일로 저장

## 2. QR 코드 인식 프로그램

### **프로그램 시작 및 초기화**

```python
class QRCodeDetectNode(Node):
    def __init__(self, name):
        rclpy.init()  # ROS2 초기화
        super().__init__(name)  # 노드 초기화
        self.running = True
        self.bridge = CvBridge()  # ROS 이미지 메시지와 OpenCV 이미지 간 변환을 위한 브리지
        self.image_queue = queue.Queue(maxsize=2)  # 최대 2개의 이미지를 저장하는 큐
        # 카메라 이미지 구독 (토픽: /ascamera/camera_publisher/rgb0/image)
        self.image_sub = self.create_subscription(Image, '/ascamera/camera_publisher/rgb0/image', self.image_callback, 1)
        # 메인 함수를 별도 스레드에서 실행 (데몬 스레드)
        threading.Thread(target=self.main, daemon=True).start()
```

- **초기화 과정**
    1. ROS2 초기화 및 노드 생성
    2. CvBridge 생성 (ROS 이미지 ↔︎ OpenCV 이미지 변환)
    3. 이미지 큐 생성 (크기: 2)
    4. 카메라 이미지 토픽 구독 설정 (`image_callback` 함수 연결)
    5. 메인 처리 루프를 별도 스레드에서 시작

### **이미지 수신 (콜백 함수)**

```python
def image_callback(self, ros_image):
    cv_image = self.bridge.imgmsg_to_cv2(ros_image, "bgr8")  # ROS 이미지 메시지를 OpenCV 이미지로 변환 (BGR 형식)
    bgr_image = np.array(cv_image, dtype=np.uint8)
    if self.image_queue.full():
        self.image_queue.get()  # 큐가 가득 찬 경우 가장 오래된 이미지 제거 (최신 이미지 유지)
    self.image_queue.put(bgr_image)  # 새 이미지를 큐에 추가
```

- **큐 사용 이유**
    - 이미지 처리 속도가 이미지 수신 속도보다 느릴 수 있으므로, 큐를 사용하여 최신 이미지만 처리
    - 큐 크기를 2로 제한하여 메모리 사용량을 제어

### **QR 코드 검출 및 처리 (메인 루프)**

```python
def main(self):
    while self.running:
        try:
            # 큐에서 이미지 가져오기 (최대 1초 대기)
            image = self.image_queue.get(block=True, timeout=1)
        except queue.Empty:
            # 큐가 비어있으면 계속 대기
            if not self.running:
                break
            else:
                continue

        # QR 코드 검출 및 디코딩
        decoded_objects = pyzbar.decode(image)
        
        # 검출된 각 QR 코드에 대해 처리
        for obj in decoded_objects:
            points = obj.polygon  # QR 코드의 다각형 좌표
            
            # 4개 이상의 점이 있는 경우 볼록 껍질 계산
            if len(points) > 4:
                hull = cv2.convexHull(np.array([point for point in points], dtype=np.float32))
                points = hull.reshape(-1, 2)
            
            # QR 코드의 경계선 그리기 (초록색 선)
            for j in range(len(points)):
                cv2.line(image, tuple(points[j]), tuple(points[(j+1) % len(points)]), (0, 255, 0), 3)
            
            # QR 코드의 위치 정보 가져오기
            x = obj.rect.left  # 왼쪽 상단 x 좌표
            y = obj.rect.top   # 왼쪽 상단 y 좌표
            
            # 디코딩된 데이터 (UTF-8 문자열로 변환)
            barcode_data = obj.data.decode("utf-8")
            print(barcode_data)  # 콘솔에 출력
            
            # 이미지에 텍스트 표시
            cv2.putText(image, barcode_data, (x, y - 10), cv2.FONT_HERSHEY_SIMPLEX, 0.5, (0, 255, 0), 2)

        # 결과 이미지 화면에 표시
        cv2.imshow('image', image)
        key = cv2.waitKey(1)
        if key == ord('q') or key == 27:  # 'q' 또는 ESC 키로 종료
            break

    # OpenCV 창 닫기
    cv2.destroyAllWindows()
    rclpy.shutdown()
```

- **처리 단계**
    1. **이미지 가져오기**: 큐에서 이미지 가져오기 (최대 1초 대기)
    2. **QR 코드 검출**: `pyzbar.decode()`로 이미지에서 QR 코드 검출
    3. **다각형 처리**: 4개 이상의 점이 있으면 볼록 껍질 계산
    4. **경계선 그리기**: QR 코드의 경계를 초록색 선으로 표시
    5. **텍스트 표시**: 디코딩된 데이터를 QR 코드 위에 텍스트로 표시
    6. **콘솔 출력**: 디코딩된 데이터를 콘솔에 출력
    7. **화면 표시**: 처리된 이미지를 화면에 표시


### **메인 함수**

```python
def main():
    node = QRCodeDetectNode('qrcode_detect')  # 노드 생성
    try:
        rclpy.spin(node)  # ROS2 스핀 (콜백 함수 실행)
    except KeyboardInterrupt:
        node.destroy_node()  # 노드 정리
        rclpy.shutdown()  # ROS2 종료
        print('shutdown')
    finally:
        print('shutdown finish')

if __name__ == "__main__":
    main()
```
