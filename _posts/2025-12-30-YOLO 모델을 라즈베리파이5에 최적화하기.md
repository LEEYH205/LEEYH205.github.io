# 1단계) 딥러닝 모델 포맷 변경하기

---

## 개요

> 현재 타겟 디바이스인 Raspberry Pi 5에서 640x480 해상도의 영상을 CPU로 추론해보았는데요, 추론 속도가 조금 더 빨랐으면 좋겠다라는 생각이 듭니다. 따라서 이번 챕터에서는 Ultralytics YOLO(`yolov8m.pt`, `yolo11n.pt` 등) 모델을 **라즈베리파이 5** 환경에 **최적화된 포맷**으로 변환하는 방법을 익혀보도록 하겠습니다.
> 

## 딥러닝 모델 포맷

### 여기서 말하는 포맷이란 무엇일까요?

> **포맷(format)**은 딥러닝 모델을 저장하거나 배포할 때 사용되는 파일 형태(모델 표현 방식)을 말합니다. ****동일한 신경망 모델이라도 어떤 구조로 저장하느냐에 따라 포맷이 달라지죠.
> 
- **딥러닝 모델 포맷 = 모델의 구조(네트워크 그래프) + 가중치(weights) 를 어떤 방식으로 저장하는지에 대한 규격**
    - 어떤 구조로 기록할지(그래프 정의 방식)
    - 어떤 파일 형태로 저장할지
    - 어떤 프레임워크·런타임에서 읽을 수 있는지
    - 어떤 디바이스(CPU/GPU/모바일)에서 잘 돌 수 있는지

| **포맷** | **프레임워크** | **특징** | **장점** | **단점** |
| --- | --- | --- | --- | --- |
| **PyTorch 모델 (.pt, .pth)** | PyTorch | 가장 기본 형태(Python 객체 그래프) | 개발·연구 편함, 디버깅 쉬움 | Python 의존 → 배포 어려움 |
| **TorchScript (.pt)** | PyTorch | PyTorch 모델을 그래프로 변환 | Python 없이 배포 가능, C++ 지원 | 복잡한 Python 코드 변환 어려움 |
| **ONNX (.onnx)** | - | 공통 교환 포맷 | 호환성 최고, 다양한 가속기 지원 | 연산자 미지원 이슈, 디버깅 어려움 |
| **OpenVINO IR (.xml + .bin)** | Intel | Intel HW 최적화 모델 | CPU 속도 최강, VPU 지원 | Intel HW 특화 |
| **TF SavedModel** | TensorFlow | 디렉토리 형태 모델 | 기능 풍부, 서빙(TF Serving) 최적 | 구조 복잡, 무겁다 |
| **TF GraphDef (.pb)** | TensorFlow | 그래프 정의 단일 파일 | 단순, 소형화 용이 | TF2에서는 권장 X |
| **TF Lite (.tflite)** | TensorFlow | 모바일/엣지 최적화 | 매우 가벼움, 양자화 강력 | 연산자 제한 많음 |
| **PaddlePaddle (.pdmodel)** | Paddle | 중국 Baidu 생태계 중심 | 중국 HW 가속기 지원 좋음 | 글로벌 생태계는 작음 |
| **MNN (.mnn)** | Alibaba | 초경량 추론 엔진 | 매우 빠르고 가벼움 | 생태계 작음 |
| **NCNN (.param + .bin)** | Tencent | 모바일 최적화 CNN 엔진 | Android 속도 최강, 중국 장치 강세 | 모델 변환 필요 |


### 왜 다른 포맷으로 변환해야 할까?

- **라즈베리파이 5의 한계**
    - 데스크탑 GPU처럼 강력한 CUDA 환경이 없음
    - 메모리/대역폭이 제한적이라, PyTorch 그대로 쓰면 속도/발열/전력 모두 부담
- **변환시의 이점**
    - 이미 학습되어 있는 Ultralytics YOLO 모델을 그대로 활용
    - 이후에는 Python 없이 C++/Rust 등 다른 언어로도 추론 파이프라인 구성 가능

### 라즈베리파이 5에는 어떤 포맷이 최적일까요?

> Ultralytics 팀은 속도와 [정확도](https://www.ultralytics.com/ko/glossary/accuracy)를 측정하기 위해 PyTorch, TorchScript, ONNX, OpenVINO, TF SavedModel, TF GraphDef, TF Lite, PaddlePaddle, MNN, NCNN의 10가지 모델 형식에 대해 YOLO11 벤치마크를 실행했습니다. 벤치마크는 기본 입력 이미지 크기 640에서 FP32 [정밀도](https://www.ultralytics.com/ko/glossary/precision)로 Raspberry Pi 5에서 실행되었습니다.

## 타겟 딥러닝 모델 포맷 변경하기

1. `/home/ubuntu/ros2_ws/src/yolo_ros/yolo_ros/yolo_ros` 디렉토리에 NCNN 포맷으로 변환을 위한 `export_to_ncnn.py`를 생성하고 아래 코드를 추가합니다.
    
    ```python
    #!/usr/bin/env python3
    import argparse
    from pathlib import Path
    from ultralytics import YOLO
    
    BASE_DIR = Path("/home/ubuntu")
    
    def parse_args():
        parser = argparse.ArgumentParser(
            description="Export Ultralytics YOLO model to NCNN format (Raspberry Pi)"
        )
        parser.add_argument(
            "--model",
            type=str,
            default="yolov8m.pt",
        )
        parser.add_argument(
            "--imgsz",
            type=int,
            nargs="+",
            default=[480, 640],
        )
        parser.add_argument(
            "--device",
            type=str,
            default="cpu",
        )
        return parser.parse_args()
    
    def main():
        args = parse_args()
    
        model_path = Path(args.model)
        if not model_path.is_absolute():
            model_path = BASE_DIR / model_path
    
        model = YOLO(str(model_path))
    
        # NCNN export
        model.export(
            format="ncnn",
            imgsz=args.imgsz,
            device=args.device,
        )
    
        print(f"NCNN export finished.")
    
    if __name__ == "__main__":
        main()
    ```
    
2. 아래 명령어로 
    
    ```bash
    python3 ~/ros2_ws/src/yolo_ros/yolo_ros/yolo_ros/export_to_ncnn.py \
      --model yolo11n.pt \
      --imgsz 480 640 \
      --device cpu
    ```
3. `yolo11n.pt`를 선택할 경우 최종적으로 `yolo11n_ncnn_model` 디렉토리가 생성된 것을 확인할 수 있습니다.

    | 파일 | 용도 |
    | --- | --- |
    | `model.ncnn.param` | NCNN 모델 구조 |
    | `model.ncnn.bin` | NCNN 모델 가중치 |

---

## **오버클럭이란?**

> 오버클럭(Overclocking)은 **CPU·GPU 클럭을 기본값보다 높여 성능을 끌어올리는 작업**
> 
- 라즈베리파이 5 기본 스펙
    - **CPU(arm_freq)**: 2.4GHz
    - **GPU(gpu_freq)**: 800MHz
    - **force_turbo=1**: 모든 상황에서 최대 클럭 유지

## Raspberry Pi 5에 오버클럭 설정하기

1. **LXTerminal**에서 아래 파일을 열어줍니다.
    
    ```bash
    sudo vim /boot/firmware/config.txt
    ```
    
2. 아래 굵은 글씨로 표시한 부분을 해당 위치에 추가해줍니다.
    
    ```bash
    ... 
    
    # Run as fast as firmware / board allows
    arm_boost=1
    
    # 추가!
    **arm_freq=2800
    gpu_freq=900
    force_turbo=1**
    
    ...
    ```
    
3. 재부팅을 한 후 결과를 확인합니다.
    
    ```bash
    reboot
    ```

- MediaPipe의 OD 관련 태스크가 있습니다. - `/home/ubuntu/ros2_ws/src/example/example/mediapipe_example` 에 `od.py`를 생성하고 결과를 YOLO11n 모델과 비교해 볼 수 있습니다.
    
    ```python
    #!/usr/bin/env python3
    # encoding: utf-8
    
    import os
    import cv2
    import fps
    import queue
    import rclpy
    import threading
    import numpy as np
    import mediapipe as mp
    from rclpy.node import Node
    from cv_bridge import CvBridge
    from sensor_msgs.msg import Image
    from mediapipe.tasks import python as mp_python
    from mediapipe.tasks.python import vision as mp_vision
    
    class ObjectDetectionNode(Node):
        def __init__(self, name: str):
            rclpy.init()
            super().__init__(name)
    
            self.running = True
            self.bridge = CvBridge()
            self.fps = fps.FPS()
    
            self.image_queue = queue.Queue(maxsize=2)
    
            self.image_sub = self.create_subscription(
                Image,
                '/ascamera/camera_publisher/rgb0/image',
                self.image_callback,
                1,
            )
    
            # 모델 경로 설정
            default_model_path = os.path.join(
                os.path.dirname(os.path.abspath(__file__)),
                'model',
                'ssd_mobilenet_v2.tflite',
                # 'efficientdet_lite0.tflite'
            )
            self.model_path = self.declare_parameter(
                'model_path',
                default_model_path
            ).get_parameter_value().string_value
    
            # MediaPipe Object Detector 생성
            self.detector = self.create_detector(self.model_path)
    
            self.get_logger().info('\033[1;32m%s\033[0m' % 'object detection start')
            # 메인 처리 쓰레드 시작
            threading.Thread(target=self.main, daemon=True).start()
    
        def create_detector(self, model_path: str):
            base_options = mp_python.BaseOptions(model_asset_path=model_path)
            options = mp_vision.ObjectDetectorOptions(
                base_options=base_options,
                running_mode=mp_vision.RunningMode.IMAGE,
                score_threshold=0.5,
                max_results=5,
            )
            detector = mp_vision.ObjectDetector.create_from_options(options)
            self.get_logger().info(f'Use model: {model_path}')
            return detector
    
        def image_callback(self, ros_image: Image):
            # ROS Image → OpenCV RGB
            cv_image = self.bridge.imgmsg_to_cv2(ros_image, 'rgb8')
            rgb_image = np.array(cv_image, dtype=np.uint8)
    
            # 큐가 가득 차면 가장 오래된 이미지 제거
            if self.image_queue.full():
                self.image_queue.get()
            self.image_queue.put(rgb_image)
    
        def detect_objects(self, rgb_image: np.ndarray) -> np.ndarray:
            # MediaPipe Image 변환
            mp_image = mp.Image(
                image_format=mp.ImageFormat.SRGB,
                data=rgb_image,
            )
    
            # Object Detection 수행
            detection_result = self.detector.detect(mp_image)
    
            annotated = rgb_image.copy()
    
            if detection_result.detections:
                for detection in detection_result.detections:
                    bbox = detection.bounding_box
                    x_min = int(bbox.origin_x)
                    y_min = int(bbox.origin_y)
                    x_max = int(bbox.origin_x + bbox.width)
                    y_max = int(bbox.origin_y + bbox.height)
    
                    # 박스 그리기
                    cv2.rectangle(
                        annotated,
                        (x_min, y_min),
                        (x_max, y_max),
                        (0, 255, 0),
                        2,
                    )
    
                    # 라벨(클래스 + score) 그리기
                    if detection.categories:
                        category = detection.categories[0]
                        category_name = category.category_name or ''
                        score = category.score or 0.0
                        label = f'{category_name}: {score:.2f}'
    
                        cv2.putText(
                            annotated,
                            label,
                            (x_min, max(0, y_min - 10)),
                            cv2.FONT_HERSHEY_SIMPLEX,
                            0.5,
                            (0, 255, 0),
                            1,
                            cv2.LINE_AA,
                        )
    
            return annotated
    
        def main(self):
            while self.running:
                try:
                    image = self.image_queue.get(block=True, timeout=1)
                except queue.Empty:
                    if not self.running:
                        break
                    else:
                        continue
    
                # Object Detection 수행
                annotated_rgb = self.detect_objects(image)
                # OpenCV 표시용 BGR 변환
                annotated_bgr = cv2.cvtColor(annotated_rgb, cv2.COLOR_RGB2BGR)
    
                # FPS 표시
                self.fps.update()
                result_image = self.fps.show_fps(annotated_bgr)
    
                cv2.imshow('MediaPipe Object Detection', result_image)
                key = cv2.waitKey(1)
                if key == ord('q') or key == 27:
                    break
    
            cv2.destroyAllWindows()
            rclpy.shutdown()
    
    def main():
        node = ObjectDetectionNode('mediapipe_od')
        try:
            rclpy.spin(node)
        except KeyboardInterrupt:
            node.destroy_node()
            rclpy.shutdown()
            print('shutdown')
        finally:
            print('shutdown finish')
    
    if __name__ == '__main__':
        main()
    ```
