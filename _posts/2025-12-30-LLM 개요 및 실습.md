# LLM 개요

---

## LLM(Large Language Model)이란?

> 수십억~수천억 개의 파라미터를 가진 딥러닝 모델로, 대량의 텍스트 데이터를 학습하여 **자연어 이해 및 생성** 능력을 갖춘 AI
> 

| 구분 | 설명 |
| --- | --- |
| **입력** | 자연어 텍스트(프롬프트) |
| **출력** | 자연어 텍스트(응답, 코드, JSON 등) |
| **핵심 구조** | Transformer (Self-Attention 메커니즘) |
| **대표 모델** | GPT-5, Claude, Gemini, Llama, Qwen 등 |

## LLM의 핵심 개념

### 프롬프트(Prompt)

> LLM에게 전달하는 입력 텍스트
> 
- 프롬프트를 어떻게 작성하느냐에 따라 출력 품질이 크게 달라짐
    
    ```
    [System] 너는 서비스 로봇의 안내 AI다.
    [User]   12층 1207호에 생수 2병 배달해줘.
    [Assistant] 네, 12층 1207호로 생수 2병 배달을 시작하겠습니다...
    ```

### 토큰(Token)

> LLM이 텍스트를 처리하는 최소 단위
> 
- 영어: 약 4글자 = 1토큰
- 한글: 약 1~2글자 = 1토큰 정도

### Temperature

> 출력의 **창의성/무작위성**을 조절하는 파라미터
> 
- `0.0 ~ 0.3`: 일관되고 결정적인 응답 (로봇 명령 추출에 적합)
- `0.7 ~ 1.0`: 다양하고 창의적인 응답 (대화/브레인스토밍에 적합)

## 로보틱스에서 LLM이 주목받는 이유

> 전통적인 로봇 소프트웨어는 **정해진 규칙**에 따라 동작했지만, LLM을 활용하면 사용자의 **자연어 명령**을 로봇이 이해할 수 있는 **구조화된 명령**으로 변환할 수 있습니다.
> 

| 기존 방식 | LLM 활용 방식 |
| --- | --- |
| “배달해줘” → 키워드 매칭 실패 | “12층에 물 좀 갖다줘” → 의도 파악 성공 |
| 정해진 문장만 인식 | 다양한 표현 이해 |
| 새 기능 = 코드 수정 필요 | 프롬프트 수정으로 행동 변경 가능 |

### 로봇에서의 LLM 활용

| 트렌드 | 설명 | 예시 |
| --- | --- | --- |
| **Embodied AI** | LLM이 물리적 환경에서 행동하는 에이전트 | Google RT-2, Figure 01 |
| **VLM (Vision-Language Model)** | 이미지+텍스트를 함께 이해 | GPT-4V, Gemini Pro Vision |
| **Edge LLM** | 소형 모델을 로컬에서 실행 | Phi-3, Gemma, Llama 3.2 |
| **Tool Use / Function Calling** | LLM이 외부 API/함수를 호출 | ROS2 서비스 호출 등 |
| **Multi-Agent** | 여러 LLM 에이전트가 협업 | 계획 에이전트 + 실행 에이전트 |

### 예상 활용 시나리오

- **음성 명령 기반 주행**: “빨간 공 앞으로 가줘”
- **상태 진단 도우미**: 텔레메트리를 LLM에 전달 → 문제 원인 추정
- **멀티턴 미션 플래닝**: 대화를 통해 복잡한 미션 계획 수립
- **카메라 영상 분석**: VLM으로 전방 장애물/표지판 인식

# OpenRouter

---

## OpenRouter란?

> 다양한 LLM 제공자(OpenAI, Anthropic, Google, Meta 등)의 모델을 **하나의 통합 API**로 접근할 수 있게 해주는 서비스
>

### OpenRouter를 왜 쓰나요?

- **무료 모델 제공**
    - `nvidia/nemotron-nano:free`, `google/gemma-3:free` 등 무료 사용 가능
- **OpenAI 호환 API**
    - 기존 OpenAI 코드를 거의 수정 없이 사용 가능
- **모델 전환 용이**
    - `model` 파라미터만 바꾸면 다른 모델로 즉시 전환
- **다양한 모델 검색 및 가격 비교**
    - 여러 제공자 가격 비교 후 선택 가능
- **Rate Limit 분산**
    - 제공자 제한에 걸려도 다른 모델로 대체 가능

### 라즈베리파이5 같은 저사양 SBC에서 OpenRouter를 쓰면 좋은 이유

| 항목 | 로컬 LLM | 클라우드 LLM |
| --- | --- | --- |
| 필요 RAM | 8GB+ | 수 MB (API 호출만) |
| 응답 속도 | 10~60초 | 1~5초 |
| 전력 소모 | 높음 | 낮음 |
| 모델 선택 | 소형 모델만 | GPT-5급 모델도 사용 가능 |
| 인터넷 | 불필요 | **필요** |

## 설정 파일 작성

### config.json

> API 키와 모델 설정을 담는 JSON 파일
> 

```json
{
  "provider": "openrouter",
  "api_key_env": "OPENROUTER_API_KEY",
  "api_key": "발급받은 key를 넣어주세요!",
  "base_url": "https://openrouter.ai/api/v1",
  "llm_model": "nvidia/nemotron-nano-9b-v2:free",
  "vlm_model": "amazon/nova-2-lite-v1:free",
  "http": {
    "timeout_sec": 60
  },
  "generation": {
    "temperature": 0.2,
    "top_p": 0.9,
    "max_tokens": 512
  }
}
```

- **주요 설정 설명**
    - `api_key` : OpenRouter에서 발급받은 API 키
    - `base_url` : OpenRouter API 엔드포인트
    - `llm_model` : 텍스트 전용 모델
    - `vlm_model` : 비전(이미지) 지원 모델

### generation 파라미터

> **generation** 블록은 LLM이 텍스트를 생성하는 방식을 제어하며, 응답 품질과 일관성을 조절할 수 있음
> 
- **`temperature`**: LLM은 다음 단어를 예측할 때 여러 후보 단어에 대한 확률 분포를 계산하게 되는데, 이 때 LLM이 다음 토큰을 선택할 때의 **무작위성(randomness)**을 조절
    
    
    | 값 | 특성 | 적합한 용도 |
    | --- | --- | --- |
    | `0.0` | 완전 결정적 (항상 같은 답) | JSON 파싱, 명령 추출 |
    | `0.1~0.3` | 매우 일관적 | **로봇 명령 처리 (권장)** |
    | `0.5~0.7` | 균형 | 일반 대화, 설명 |
    | `0.8~1.0` | 창의적, 다양함 | 브레인스토밍, 스토리 |
    | `>1.0` | 매우 무작위 | 거의 사용 안 함 |
- **`top_p`**: 누적 확률이 `top_p`에 도달할 때까지의 상위 토큰들만 후보로 고려
    
    ```
    예시: top_p = 0.9 일 때
    
    단어별 확률:
    좋다(40%) + 맑다(30%) + 흐리다(15%) + 덥다(5%) = 90% ← 여기까지만 후보
    ───────────────────────────────────────────────────
    춥다(4%), 습하다(3%), 시원하다(2%), ... ← 제외됨
    ```
    
    | 값 | 효과 |
    | --- | --- |
    | `1.0` | 모든 토큰 고려 (top_p 비활성화) |
    | `0.9` | 상위 90% 확률의 토큰만 고려 **(일반적 권장값)** |
    | `0.5` | 상위 50%만 고려 (매우 보수적) |
- **`max_tokens`**: LLM이 생성할 **최대 출력 길이**를 토큰 단위로 제한
    - 너무 작으면 응답이 **중간에 잘릴 수 있음**
    - 너무 크면 **불필요하게 긴 응답** + **비용/시간 증가**
    - 무료 모델은 보통 4096~8192 토큰 제한이 있음


## 공통 유틸리티 파일

### common.py

> OpenRouter API 호출을 위한 공통 함수들을 정의
> 

```python
import base64
import json
import mimetypes
import os
from pathlib import Path
from typing import Any, Dict, Iterable, List, Optional

from openai import OpenAI

def _config_path() -> Path:
    return Path(__file__).resolve().parent / "config.json"

def load_config() -> Dict[str, Any]:
    """같은 디렉토리의 config.json을 읽어 설정을 반환"""
    cfg_path = _config_path()
    with cfg_path.open("r", encoding="utf-8") as f:
        return json.load(f)

def get_api_key(cfg: Dict[str, Any]) -> str:
    """config.json + 환경변수에서 API 키를 가져옴"""
    env_name = (cfg.get("api_key_env") or "OPENROUTER_API_KEY").strip()
    api_key = os.getenv(env_name, "").strip()
    if api_key:
        return api_key

    # 마지막 fallback: config.json의 api_key
    api_key = (cfg.get("api_key") or "").strip()
    if api_key:
        return api_key

    raise RuntimeError(
        f"Missing OpenRouter API key. Set environment variable {env_name} or fill config.json api_key."
    )

def get_client(cfg: Optional[Dict[str, Any]] = None) -> OpenAI:
    """OpenRouter(OpenAI 호환) 클라이언트를 생성"""
    cfg = cfg or load_config()
    api_key = get_api_key(cfg)
    base_url = (cfg.get("base_url") or "https://openrouter.ai/api/v1").strip()

    timeout_sec = 60
    http_cfg = cfg.get("http") or {}
    if isinstance(http_cfg, dict):
        timeout_sec = int(http_cfg.get("timeout_sec") or timeout_sec)

    return OpenAI(api_key=api_key, base_url=base_url, timeout=timeout_sec)

def default_generation_params(cfg: Dict[str, Any]) -> Dict[str, Any]:
    gen = cfg.get("generation") or {}
    if not isinstance(gen, dict):
        gen = {}
    return {
        "temperature": gen.get("temperature", 0.7),
        "top_p": gen.get("top_p", 0.9),
        "max_tokens": gen.get("max_tokens", 512),
    }

def chat_complete(
    *,
    client: OpenAI,
    model: str,
    messages: List[Dict[str, Any]],
    **kwargs: Any,
) -> str:
    """일반(비스트리밍) 채팅 완료, 최종 텍스트를 반환"""
    resp = client.chat.completions.create(model=model, messages=messages, **kwargs)
    return (resp.choices[0].message.content or "").strip()

def chat_complete_raw(
    *,
    client: OpenAI,
    model: str,
    messages: List[Dict[str, Any]],
    **kwargs: Any,
) -> Any:
    """일반(비스트리밍) 채팅 완료, raw 응답을 반환"""
    return client.chat.completions.create(model=model, messages=messages, **kwargs)

def chat_stream(
    *,
    client: OpenAI,
    model: str,
    messages: List[Dict[str, Any]],
    **kwargs: Any,
) -> Iterable[str]:
    """스트리밍 채팅 완료, 토큰(델타)을 순차적으로 yield"""
    stream = client.chat.completions.create(model=model, messages=messages, stream=True, **kwargs)
    for event in stream:
        delta = event.choices[0].delta
        if delta and getattr(delta, "content", None):
            yield delta.content

def image_file_to_data_url(image_path: str) -> str:
    """로컬 이미지 파일을 OpenAI/OpenRouter 비전 입력에 쓰는 data URL로 변환"""
    p = Path(image_path)
    if not p.exists():
        raise FileNotFoundError(f"Image file not found: {image_path}")

    mime, _ = mimetypes.guess_type(str(p))
    if not mime:
        mime = "image/png"

    raw = p.read_bytes()
    b64 = base64.b64encode(raw).decode("utf-8")
    return f"data:{mime};base64,{b64}"

```


## 실습 1: LLM 기본 호출 (llm_basic.py)

> 서비스 로봇의 사용자 요청을 처리하는 예제
> 

```python
from common import (
    chat_complete,
    default_generation_params,
    get_client,
    load_config,
)

def main() -> None:
    cfg = load_config()
    client = get_client(cfg)

    system_rule = """
너는 실내 서비스 로봇의 "대화형 안내/접수" 역할을 하는 한국어 AI다.
- 사용자는 로봇을 처음 쓰는 사람일 수 있으니 친절하고 짧게 안내한다.
- 질문이 모호하면 확인 질문을 1~2개만 한다.
- 안전(사람/휠체어/유모차/문턱/계단)과 사생활(촬영/개인정보)은 보수적으로 안내한다.
- 출력 형식:
  1) 한 줄 요약
  2) 로봇이 할 행동(최대 4개)
  3) 사용자에게 확인할 질문(최대 2개)
""".strip()

    user_prompt = """
나는 호텔 로비에 있는 손님이야. 서비스 로봇에게 이렇게 부탁하고 싶어.

"제가 12층 1207호인데요, 생수 2병이랑 수건 1세트를 가져다줄 수 있을까요?
지금 문 앞에 두고 가도 되고, 도착하면 로비 전화 말고 제 휴대폰으로 알려주세요.
그리고 복도에 사람이 많으면 천천히 와주세요."

위 요청을 로봇이 이해하기 쉽게 정리해서, 로봇이 어떤 순서로 진행하면 좋을지 안내해줘.
""".strip()

    messages = [
        {"role": "system", "content": system_rule},
        {"role": "user", "content": user_prompt},
    ]

    params = default_generation_params(cfg)
    text = chat_complete(
        client=client,
        model=cfg["llm_model"],
        messages=messages,
        **params,
    )

    print("=== Model Output ===")
    print(text)

if __name__ == "__main__":
    main()
```

- **예제 시나리오**
    - 호텔 손님이 서비스 로봇에게 객실 배송 요청
    - LLM이 요청을 분석하여 로봇이 수행할 단계별 행동 제안
- **실행 방법**
    
    ```bash
    python3 ~/ros2_ws/src/large_models/large_models/openrouter/llm_basic.py
    ```

## 실습 2: LLM 스트리밍 출력 (lm_streaming.py)

> 로봇 관제 시스템에서 즉각적인 피드백이 필요할 때, 토큰이 생성되는 대로 실시간으로 출력하는 예제
> 
> 
> 
> | 방식 | 특징 | 적합한 상황 |
> | --- | --- | --- |
> | **일반** | 전체 응답 완료 후 한 번에 반환 | 짧은 응답, 후처리 필요 시 |
> | **스트리밍** | 토큰 단위로 실시간 출력 | 긴 응답, 즉각적 피드백 필요 시 |

```python
from common import (
    chat_stream,
    default_generation_params,
    get_client,
    load_config,
)

def main() -> None:
    cfg = load_config()
    client = get_client(cfg)

    system_rule = """
너는 모바일 로봇 관제용 한국어 AI 어시스턴트다.
- 운영자에게 즉시 조치 가능한 형태로 답한다.
- 위험 징후(배터리 급감, 충돌 가능성, 센서 이상, 로컬라이제이션 실패)는 최우선으로 강조한다.
- 답변은 마크다운 형식으로 출력한다.
- 출력은 짧은 요약 후 체크리스트로 이어간다.
""".strip()

    user_prompt = """
다음은 모바일 로봇의 최근 텔레메트리 요약이다.

[텔레메트리]
- battery: 18%
- cpu: 82%
```

## 실습 3: 멀티턴 대화 (llm_multiturn_memory.py)

> 이전 대화 내용을 기억하며 연속적인 대화를 수행하는 예제
> 

```python
from typing import Dict, List

from common import (
    chat_complete,
    default_generation_params,
    get_client,
    load_config,
)

def main() -> None:
    cfg = load_config()
    client = get_client(cfg)
    params = default_generation_params(cfg)

    system_rule = """
너는 모바일 로봇 관제용 한국어 AI 오퍼레이터다.
- 사용자가 제공한 환경/제약/금지구역/목표를 기억해서 다음 턴에 반영한다.
- 안전 관련 판단은 보수적으로 한다.
- 답변은 8줄 이내로 간결하게.
- 마지막 줄에 반드시 "다음 확인: ..." 형태로 질문 1개를 덧붙인다.
""".strip()

    history: List[Dict[str, str]] = [{"role": "system", "content": system_rule}]

    # 1턴: 미션 요청
    history.append(
        {
            "role": "user",
            "content": "mentorpi 모바일 로봇으로 '프론트 데스크 -> 회의실 A' 문서 배송을 시키고 싶어. 사람 많은 구간이 있고 서버룸 앞은 금지구역이야. 어떻게 운영하면 좋을까?",
        }
    )
    a1 = chat_complete(client=client, model=cfg["llm_model"], messages=history, **params)
    print("=== Turn 1 Answer ===")
    print(a1)

    history.append({"role": "assistant", "content": a1})

    # 2턴: 상태 업데이트 + 추가 지시
    history.append(
        {
            "role": "user",
            "content": "지금 배터리가 16%이고, 방금 로컬라이제이션이 2번 튀었어. 그래도 배송을 계속해야 할까? 중단한다면 어떤 절차로 중단하는 게 안전할까?",
        }
    )
    a2 = chat_complete(client=client, model=cfg["llm_model"], messages=history, **params)
    print("\n=== Turn 2 Answer ===")
    print(a2)

if __name__ == "__main__":
    main()
```

- **예제 시나리오**
    - **1턴**: 로봇 배송 미션 계획 요청
    - **2턴**: 배터리 부족 + 로컬라이제이션 불안정 상황에서 계속/중단 판단 요청
- **실행 방법**
    
    ```bash
    python3 ~/ros2_ws/src/large_models/large_models/openrouter/llm_multiturn_memory.py
    ```
