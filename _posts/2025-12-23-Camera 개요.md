# Camera

---

## 개요


다양한 종류의 카메라

- 카메라는 렌즈를 통해 수집한 빛을 이미지 센서에 전달하고, 이미지 센서는 빛의 강도와 색상 정보를 전기 신호로 변환. 이후, 색상 필터 패턴 (예: Bayer 필터)을 사용하여 각 픽셀의 색상 정보를 분리하고, 이를 재구성하여 최종 컬러 이미지를 형성(=debayering)
- 필터를 사용하지 않으면 Monochrome 카메라, 또는 RGB가 아닌 다른 특정 파장으로 특수 카메라 (e.g. 열화상 카메라, 적외선 카메라)를 만들 수 있음


## 특징

- **장점**
    - 사람이 보는 시야와 가장 유사한 데이터를 뽑음
    - 저렴한 센서임에도 texture가 충만한 dense한 정보를 가짐
    - FPS가 높은 편 (30fps, 60fps)
    - 렌즈를 바꿈으로써 시야각을 바꿀 수 있음 (광각 카메라)

        
- **단점**
    - Monocular Camera의 경우 Depth 정보가 없음(Stereovision을 통해 Depth를 구현할 수 있지만, 계산량이 적지 않음)
    - 조명에 대한 영향을 많이 받음
        - 어두운 곳에서는 좋은 데이터가 많이 안들어옴
        - 너무 밝거나 빛반사가 카메라에 바로 오는 경우 작동하지 않을 수 있음
    - Motion Blur
        

# Monocular Camera

## **GC0308 HD Camera 170°**

- USB 인터페이스 카메라
- 70°, 130°, 170° 등 다양한 시야각 제품 선택 가능
- 480P(640×480)~1080P 해상도 지원

## 주요 사양

| **항목** | **사양** |
| --- | --- |
| **Photosensitive chip** | GC0308(GalaxyCore) |
| **Resolution** | 30만 화소 (640×480) |
| **Lens type** | HS-256-650(HS) |
| **Aperture** | 2.0 |
| **Focal distance** | 1.7mm |
| **Focus field of view** | 170° |
| **Distortion** | -83% |
| **Size** | 30×27×25mm |

## SBC

### **카메라 드라이버**

1. Depth Camera (`peripherals/launch/include/ascamera.launch.py`)
    
    ```bash
    launch_ros.actions.Node(
        namespace="ascamera",
        package='ascamera',
        executable='ascamera_node',
        respawn=True,
        output='both',
        parameters=[
            {"usb_bus_no": -1},
            {"usb_path": "null"},
            {"confiPath": "/home/ubuntu/third_party_ros2/third_party_ws/src/ascamera/configurationfiles"},
            {"color_pcl": True},
            {"pub_tfTree": True},
            {"depth_width": 640},
            {"depth_height": 480},
            {"rgb_width": 640},
            {"rgb_height": 480},
            {"fps": 15},
        ]
    ),
    ```
    
    - 출력 토픽:
        - `/ascamera/camera_publisher/rgb0/image` (RGB 이미지)
        - `/ascamera/camera_publisher/rgb0/camera_info` (카메라 정보)
        - `/ascamera/camera_publisher/depth0/image_raw` (Depth 이미지)
2. Monocular Camera (`peripherals/launch/usb_cam.launch.py`)
    
    ```bash
    camera_nodes = Node(
            package='usb_cam', 
            executable='usb_cam_node_exe', 
            output='screen',
            name='usb_cam',
            parameters=[os.path.join(peripherals_package_path, 'config', 'usb_cam_param.yaml')],
            remappings = [
                ('image_raw', '/ascamera/camera_publisher/rgb0/image'),
                ('image_raw/compressed', '/ascamera/camera_publisher/rgb0/image_compressed'),
                ('image_raw/compressedDepth', '/ascamera/camera_publisher/rgb0/compressedDepth'),
                ('image_raw/theora', '/ascamera/camera_publisher/rgb0/image_raw/theora'),
                ('camera_info', '/ascamera/camera_publisher/rgb0/camera_info'),
            ]
        )
    ```
    
    - 출력 토픽: `/ascamera/camera_publisher/rgb0/image`
