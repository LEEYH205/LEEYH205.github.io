# **LiDAR (Light Detection And Ranging)**

---

## 개요


- **적외선 레이저를 쏘아 반사되어 돌아오는 시간을 측량하여 거리를 잴 수 있는 센서**

## LiDAR 동작 및 거리 측정 원리

### Time of Flight (TOF)
![](/assets/img/HiWonderPi/img/download/TOF.png)
- LiDAR는 처음에 물체에 빛을 투사합니다. 물체는 빛을 LiDAR로 직접 반사하며, LiDAR는 빛이 돌아오는 데 걸리는 시간을 계산합니다. 물체와 LiDAR 사이의 거리는 이 시간에 빛의 속도를 곱하여 구합니다.

### Triangulation (삼각 측량)
![](/assets/img/HiWonderPi/img/download/Triangulation.png)
- 레이저 발사 각과 반사된 빛이 센서에 닿는 위치만으로 삼각형의 성질을 이용해 거리를 구하는 원리
    - 센서(레이저 발사 지점), 반사된 빛이 닿는 지점, 그리고 반사체(장애물)가 삼각형을 이루는 구조

## LiDAR 동작 결과
![](/assets/img/HiWonderPi/img/download/LiDAR%20동작%20결과.png)
- LiDAR는 빛을 발산하여 물체 표면에 비추고, 물체에 반사된 빛을 수신하면 LiDAR는 빛이 반사된 위치에서 물체의 윤곽을 표시할 수 있습니다.


# 2D LiDAR

---

## STL-19P

- 360° 전방위 레이저 스캐닝, TOF(Time-of-Flight) 측정 기술 탑재
- 최대 측정 거리 12m(흰색 물체), 8m(검은색 물체)
    - **검은색 물체**는 빛을 흡수하고 반사율이 낮기 때문에, 같은 거리에서도 센서가 반사 신호를 덜 받게 됨
- ±45mm 평균 측정 정확도, 장거리에서도 정확도 유지
- 강한 빛(최대 30000Lux)에도 견딜 수 있는 필터 기술 적용
- ROS / ROS2, Raspberry Pi, Jetson Nano 등 지원 및 SDK 제공
- 10000시간 서비스 수명(BLDC 모터 사용)
- 소형·경량(42g), 저전력 설계

# MentorPi에서 사용되는 부분

## SBC

### LiDAR 드라이버

- bringup 및 Topic 처리 (`peripherals/launch/include/ldlidar_LD19.launch.py`)
    
    ```python
    ld19_node = Node(
        package='ldlidar_stl_ros2',
        executable='ldlidar_stl_ros2_node',
        name='LD19',
        output='screen',
        parameters=[
            {
                'topic_name': 'scan',
                'product_name': 'LDLiDAR_LD19',
                'port_baudrate': 230400,
                'port_name': '/dev/ldlidar',
                'frame_id': lidar_frame,
                'laser_scan_dir': True,
                'enable_angle_crop_func': False,
                'angle_crop_min': 135.0,
                'angle_crop_max': 225.0
            }
        ],
        remappings=[('scan', scan_raw)]
    )
    ```
    

### LiDAR 데이터 사용

1. 2D LiDAR Only Odometry (`driver/controller/launch/rf2o_laser_odometry.launch.py`)
    
    ```python
    Node(
        package='rf2o_laser_odometry',
        executable='rf2o_laser_odometry_node',
        name='rf2o_laser_odometry',
        output='screen',
        parameters=[{
            'laser_scan_topic' : '/scan_raw',
            'odom_topic' : '/odom_rf2o',
            'publish_tf' : False,
            'base_frame_id' : 'base_footprint',
            'odom_frame_id' : 'odom',
            'init_pose_from_topic' : '',
            'freq' : 10.0}],
        arguments=['--ros-args', '--log-level', 'WARN'],
    ),
    ```
    
    - 입력: `/scan_raw`
    - 출력: `/odom_rf2o`
    - 용도: EKF 센서 퓨전에 사용 (선택적)
2. SLAM (`slam/config/slam.yaml`)
    
    ```yaml
    /**:
      ros__parameters:
    	  
    	  ...
    		scan_topic: scan_raw
    		...
    ```
    
    - 입력: `/scan_raw`
    - 용도: 실시간 지도 생성 및 로봇 위치 추정
    - 설정
        - `max_laser_range`: 12.0m
        - `scan_buffer_size`: 20
        - `use_scan_matching`: true
3. Navigation (경로 계획 및 장애물 회피)
4. 기타 Application
    1. LiDAR 단독 장애물 회피
    2. LiDAR 기반 Folllower
    3. LiDAR Guarding
