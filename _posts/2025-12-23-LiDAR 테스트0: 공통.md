# LiDAR 관련 Application

---

> `app/app/lidar_controller.py`는 MentorPi 로봇의 라이다(LiDAR) 센서를 활용한 자율주행 기능을 구현한 ROS2 노드입니다. 이 프로젝트는 라이다 데이터를 분석하여 장애물을 감지하고 회피하는 다양한 기능을 제공합니다.
> 

![](/assets/img/HiWonderPi/img/download/LiDAR%20관련%20Application.png)

- **Mode 1: LiDAR Only Obstacle Avoidance**
    - 라이다 데이터를 분석하여 장애물을 감지하고 회피
- **Mode 2: LiDAR 기반 Following**
    - 가장 가까운 물체를 추적하며 일정 거리 유지
- **Mode 3: LiDAR Guarding**
    - 장애물을 감지하고 근처에서 회전하여 감시하는 용도


## Application 호출

- LiDAR 관련 Application 노드는 `app/launch/lidar_node.launch.py` 런치 파일을 통해 실행

    ```

**생성된 통신 인터페이스:**

- **Publisher:**
    - `mecanum_pub`: 로봇의 이동 명령을 발행 (`/controller/cmd_vel`)
        - M1
    - `servo_state_pub`: 서보 모터 제어 명령 발행
        - A1
- **Service:**
    - `~/enter`: 라이다 Application 진입
    - `~/exit`: 라이다 Application 종료
    - `~/set_running`: 실행 모드 설정 (0: 정지, 1: 회피, 2: 추적, 3: 가드)
    - `~/set_param`: 파라미터 설정 (임계값, 스캔 각도, 속도)
    - `~/init_finish`: 노드 상태 확인
- **Heartbeat:** 5초 타임아웃으로 연결 상태 모니터링

def enter_srv_callback(self, request, response):
    self.get_logger().info('\033[1;32m%s\033[0m' % 'lidar enter')
    self.reset_value()
    qos = QoSProfile(depth=1, reliability=QoSReliabilityPolicy.BEST_EFFORT)
    self.lidar_sub = self.create_subscription(LaserScan, '/scan_raw', self.lidar_callback, qos)  # 라이다 데이터 구독
    #set_servo_position(self.joints_pub, 1, ((10, 300), (5, 500), (4, 210), (3, 40), (2, 665), (1, 500)))
    response.success = True
    response.message = "enter"
    return response

def exit_srv_callback(self, request, response):
    self.get_logger().info('\033[1;32m%s\033[0m' % 'lidar exit')
    self.reset_value()
    self.mecanum_pub.publish(Twist())
    response.success = True
    response.message = "exit"
    return response
```

- **`enter_srv_callback`**: 라이다 데이터를 구독하기 시작하고 파라미터를 초기화
- **`exit_srv_callback`**: 모든 동작을 정지하고 파라미터를 초기화

### Application 실행 모드 설정

```python
def set_running_srv_callback(self, request, response):
    '''
    다양한 기능 활성화
    :param req: 0: 정지
                1: **LiDAR Only Obstacle Avoidance**
                2: **LiDAR 기반 Following**
                3: **LiDAR Guarding**
    :return:
    '''
    self.get_logger().info(str(request))
    new_running_mode = request.data
    self.get_logger().info('\033[1;32m%s\033[0m' % ("set_running " + str(new_running_mode)))
    if not 0 <= new_running_mode <= 3:
        response.success = False
        response.message = "Invalid running mode {}".format(new_running_mode)
    else:
        response.success = True
        response.message = "set_running"
        with self.lock:
            self.running_mode = new_running_mode
    self.mecanum_pub.publish(Twist())
    return response
```

- 3가지 Application 실행 모드를 설정


### 파라미터 설정

```python
def set_parameters_srv_callback(self, request, response):
    '''
    장애물 회피 임계값 및 속도 파라미터 설정
    :param req:
    :return:
    '''
    new_parameters = request.data
    new_threshold, new_scan_angle, new_speed = new_parameters
    self.get_logger().info("\033[1;32mn_t:{:2f}, n_a:{:2f}, n_s:{:2f}\033[0m".format(new_threshold, new_scan_angle, new_speed))
    if not 0.3 <= new_threshold <= 1.5:
        response.success = False
        response.message = "New threshold ({:.2f}) is out of range (0.3 ~ 1.5)".format(new_threshold)
        return response
    if not 0 <= new_scan_angle <= 90:
        response.success = False
        response.message = "New scan angle ({:.2f}) is out of range (0 ~ 90)"
        return response
    if not new_speed > 0:
        response.success = False
        response.message = "Invalid speed"
        return response

    with self.lock:
        self.threshold = new_threshold
        self.scan_angle = math.radians(new_scan_angle)
        self.speed = new_speed
        self.speed = self.speed
    return response
```

- 제어 파라미터를 설정
    - **threshold**: 0.3 ~ 1.5m 범위
    - **scan_angle**: 0 ~ 90도 범위
    - **speed**: 양수 값

### 라이다 데이터 전처리

```python
def lidar_callback(self, lidar_data):
    # 라이다 구독 콜백: LaserScan 메시지를 받을 때마다 호출됨
    twist = Twist()  # 로봇 제어 명령 메시지 초기화
    
    # 라이다 타입에 따른 데이터 처리 방식 차이
    # 데이터 크기 = 스캔 각도 / 스캔당 증가 각도
    if self.lidar_type != 'G4':
        # 일반 라이다: 앞쪽(0도) 기준으로 좌우 분리
        max_index = int(math.radians(MAX_SCAN_ANGLE / 2.0) / lidar_data.angle_increment)
        left_ranges = lidar_data.ranges[:max_index]  # 좌측 반구 데이터 (앞쪽부터)
        right_ranges = lidar_data.ranges[::-1][:max_index]  # 우측 반구 데이터 (뒤쪽부터 역순)
    elif self.lidar_type == 'G4':
        # G4 라이다: 데이터 배열 순서가 다름 (우측부터 좌측으로)
        '''
            ranges[right...->left]

                forward
                 lidar
             left 0 right

        '''
        # G4는 360도 전체 데이터에서 앞쪽 240도만 추출
        min_index = int(math.radians((360 - MAX_SCAN_ANGLE) / 2.0) / lidar_data.angle_increment)
        max_index = min_index + int(math.radians(MAX_SCAN_ANGLE / 2.0) / lidar_data.angle_increment)
        # 좌측 반구: 역순으로 뒤집어서 정면 기준으로 정렬
        left_ranges = lidar_data.ranges[::-1][min_index:max_index][::-1]
        # 우측 반구: 역순으로 뒤집어서 정면 기준으로 정렬
        right_ranges = lidar_data.ranges[min_index:max_index][::-1]
    
    with self.lock:  # 멀티스레드 환경에서 안전한 데이터 접근을 위한 락
        # 설정된 스캔 각도만큼만 데이터 사용
        angle = self.scan_angle / 2  # 좌우 각각의 스캔 각도
        angle_index = int(angle / lidar_data.angle_increment + 0.50)  # 반올림
        # 설정된 각도 범위 내의 데이터만 추출하여 NumPy 배열로 변환
        left_range, right_range = np.array(left_ranges[:angle_index]), np.array(right_ranges[:angle_index])
        ...
```

- 라이다 타입에 따라 데이터를 좌우로 분리하고, 설정된 스캔 각도만큼만 사용
    - **상수 정의**
        
        ```python
        # app/app/lidar_controller.py:22-23
        CAR_WIDTH = 0.4  # meter
        MAX_SCAN_ANGLE = 240  # 라이다 스캔 각도, 항상 가려지는 부분 제외 (도)
        ```

## 참조 라이브러리 및 유틸리티 함수

- `lidar_controller.py`는 값의 범위를 제한하기 위해 `driver/sdk/sdk/common.py`의 `set_range` 함수를 사용
    
    ```python
    def set_range(x, x_min, x_max):
        tmp = x if x > x_min else x_min
        tmp = tmp if tmp < x_max else x_max
        return tmp
    ```
    
    - 주어진 값 `x`를 `x_min`과 `x_max` 사이의 범위로 제한
    - **사용 예시**
        
        ```python
        # PID 출력값을 각속도 범위로 제한
        twist.angular.z = common.set_range(self.pid_yaw.output, -self.speed * 6.0, self.speed * 6.0)
        
        # PID 출력값을 선속도 범위로 제한
        twist.linear.x = common.set_range(self.pid_dist.output, -self.speed, self.speed)
        ```
