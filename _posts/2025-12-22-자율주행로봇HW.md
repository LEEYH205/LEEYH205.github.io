# 도커 백업 및 복구

```BASH
# 환경 백업 (이미지로 저장)
docker commit my_robot my_robot_backup:v1.0

# 다른 로봇에 환경 복제
docker save my_robot_backup:v1.0 > backup.tar
# → USB로 전달 → 다른 라즈베리파이에 로드
docker load < backup.tar
```
