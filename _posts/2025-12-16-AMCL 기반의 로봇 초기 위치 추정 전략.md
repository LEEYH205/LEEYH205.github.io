## [방법2] 터미널에서 초기 위치 설정하기

- AMCL 노드는 원하는 로봇의 초기 포즈를 게시할 수 있는 토픽을 제공합니다. `/initialpose` 토픽을 통해 초기 위치를 설정할 수 있습니다.
1. Rviz2 상의 `Publish Point` 버튼을 통해 초기 위치를 잡을 좌표가 어디인지 확인할 수 있습니다. 버튼을 누른 뒤 지도 상에서 특정 위치를 누르면 `/clicked_point` 토픽이 publish 됩니다.

    
2. `/clicked_point` 확인을 위해서 터미널을 열어 토픽을 구독합니다.
구독 중인 상태에서 `Publish Point` 버튼을 통해 지도 상의 위치를 클릭하면, `map` 프레임을 기준으로 클릭한 위치를 알 수 있습니다.

![](/assets/img/ros2nav2/gif/Peek%202025-12-16%2016-06.gif)

![](/assets/img/ros2nav2/gif/Peek%202025-12-16%2016-10.gif)


3. 아래 명령어로 /initialpose 토픽을 퍼블리싱하여 초기 위치를 설정합니다. 아래 그림과 같이 설정한 좌표인 위치 (x: 5.0, y: 0.0, z: 0.0), 회전 (x: 0.0, y: 0.0, z: 0.0, w: 1.0)으로 로봇 위치가 초기화된 것을 확인할 수 있습니다.
```bash
ros2 topic pub -1 /initialpose geometry_msgs/msg/PoseWithCovarianceStamped "{header: {stamp: {sec: 0}, frame_id: 'map'}, pose: {pose: {position: {x: 5.0, y: 0.0, z: 0.0}, orientation: {w: 1.0}}}}"
```
```
PoseWithCovarianceStamped
-> Pose : x,y,z pose 정보랑 오리엔테이션 정보도 있음.
-> Covariance : 코베리언스까지 있음. (공분산 값[이 포즈에 대한 불확실성 정보])
-> interface 이름에 Stamped가 붙어있으면, 시간정보까지 있음.
```
https://docs.ros.org/en/noetic/api/geometry_msgs/html/msg/PoseWithCovarianceStamped.html

## [방법3] 프로그램 상에서 초기위치 설정하기

- 완전 자율주행 로봇을 구현하려는 경우 로봇을 켤 때마다 터미널을 통해 로봇의 초기화를 수행하는 것을 원하지 않을 것입니다. 이를 방지하기 위해 [방법2]에서 언급했던 `/initialpose` 토픽을 활용해 초기 위치를 프로그램 상에서 정해줄 수 있습니다.

1. nav2_ws/src 디렉터리에 localizer_server라는 이름의 새 패키지를 만들고 토픽 작업에 필요한 종속성을 추가합니다.
```BASH
sudo apt install ros-humble-tf-transformations

cd ~/nav2_ws/src
ros2 pkg create --build-type ament_python localizer_server --dependencies rclpy geometry_msgs tf-transformations
```

2. 방금 생성한 패키지의 localizer_server 디렉터리에 init_robot.py라는 새 파일을 생성합니다.
3. 방금 만든 파일에 다음 코드를 복사합니다.
```PYTHON
import rclpy
from rclpy.node import Node
from geometry_msgs.msg import PoseWithCovarianceStamped
from geometry_msgs.msg import PointStamped
from tf_transformations import quaternion_from_euler

# init_pose = x, y, theta
init_pose = [3.0, 4.0, 3.141592]

class InitRobot(Node):

    def __init__(self):
        super().__init__('initial_pose_pub_node')
        self.init_pose_pub_ = self.create_publisher(PoseWithCovarianceStamped, '/initialpose', 1)
        self.clicked_point_sub_ = self.create_subscription(PointStamped, '/clicked_point', self.point_callback, 1)

        # Set initial pose after a short delay
        timer_period = 0.5  # seconds
        self.trial_count = 5
        self.timer = self.create_timer(timer_period, self.timer_callback)

    def timer_callback(self):
        self.trial_count -= 1
        self.init_pose(init_pose[0], init_pose[1], init_pose[2])

        if self.trial_count == 0:
            self.timer.cancel()  # Cancel timer after firing once

    def point_callback(self, msg):
        self.get_logger().info('Recieved Data:\n X : %f \n Y : %f \n Z : %f' % (msg.point.x, msg.point.y, msg.point.z))
        self.init_pose(msg.point.x, msg.point.y)

    def init_pose(self, x, y, theta=0.0):
        # radian to quaternion
        quat = quaternion_from_euler(0.0, 0.0, theta)

        # Publish initial pose
        msg = PoseWithCovarianceStamped()
        msg.header.frame_id = '/map'
        msg.pose.pose.position.x = x
        msg.pose.pose.position.y = y
        msg.pose.pose.position.z = 0.0
        msg.pose.pose.orientation.x = quat[0]
        msg.pose.pose.orientation.y = quat[1]
        msg.pose.pose.orientation.z = quat[2]
        msg.pose.pose.orientation.w = quat[3]

        self.get_logger().info('Publishing  Initial Position\n X= %f \n Y= %f '% (msg.pose.pose.position.x, msg.pose.pose.position.y))
        self.init_pose_pub_.publish(msg)

def main(args=None):
    rclpy.init(args=args)
    init_robot = InitRobot()

    rclpy.spin(init_robot)
    init_robot.destroy_node()
    rclpy.shutdown()

if __name__ == '__main__':
    main()
```

4. setup.py를 수정하여 init_robot.py 스크립트의 실행 파일을 entry_points에 추가합니다.
```PYTHON
entry_points={
    'console_scripts': [
        'init_pose = localizer_server.init_robot:main',
    ],
},
```
`'<executable_file_name> = <package_name>.<script_file_name>:main',`

5. 패키지를 빌드합니다.
```BASH
cd ~/nav2_ws
colcon build --symlink-install --packages-select localizer_server
```
6. 아래 명령어를 통해 노드를 실행시켜 설정한 초기 위치대로 로봇 위치가 설정되는지 확인합니다.
```bash
ros2 run localizer_server init_pose
```
