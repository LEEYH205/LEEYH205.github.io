# Recording data
## 일부 토픽만 선택적으로 레코딩
```BASH
ros2 bag record <topic 1> <topic 2> … <topic N>
```

- 지정된 토픽 중 하나가 나타나면 자동으로 인식되기 때문에 지정된 토픽이 녹화 시작 시점에 반드시 존재할 필요는 없습니다. 이 자동 기능은 `--no-discovery`를 사용하여 비활성화할 수 있습니다.
- bag file 이름은 `-o, --output`으로 지정할 수 있으며, 추가로 지정하지 않으면 현재 타임스탬프로 명명된 새 폴더를 생성하고 이 폴더에 데이터를 저장합니다.


## 모튼 토빅 레코딩(비추천)
```BASH
ros2 bag record -a
```


# 백 파일 분할
## 크기별 분할
```bash
ros2 bag record -a -b 100000
```

## 시간별 분할
```BASH
ros2 bag record -a -d 9000
```

# Replaying data
```BASH
ros2 bag play <bag>
```

# Analyzing bag file
```BASH
ros2 bag info <bag_file>
```
