# Package 생성
1. ROS 2 Docker 원격 개발 환경을 열어줍니다.
2. 먼저 ROS2 작업 공간을 생성해줍니다.
    
    ```bash
    mkdir -p ~/ros2_ws/src
    cd ~/ros2_ws/src
    ```
3. 다음으로 `ros2 pkg create` 명령을 사용하여 새 패키지를 생성합니다.
    
    ```bash
    ros2 pkg create --build-type ament_python my_package --dependencies rclpy
    ```

4. 생성된 패키지의 구조를 아래 명령어로 확인할 수 있습니다.
    
    ```bash
    cd my_package
    tree
    
    # tree 설치가 안 되었을 경우
    sudo apt install tree
    ```
5. 워크스페이스의 루트 디렉토리로 이동하여 패키지를 빌드합니다.
    
    ```bash
    cd ~/ros2_ws
    colcon build
    ```
    
6. 새로 빌드한 패키지를 사용할 수 있도록 아래 명령어를 입력하거나 새로운 터미널을 열어줍니다.
    
    ```bash
    source ~/ros2_ws/install/local_setup.bash
    
    # 또는
    
    source ~/ros2_ws/install/local_setup.zsh
    ```
    
7. 아래 명령어를 통해 패키지가 잘 설치되었는지 확인합니다.
    
    ```bash
    ros2 pkg list # 모든 ROS 시스템 패키지 목록을 제공
    ros2 pkg list | grep my_package # my_package인 패키지를 필터링
    ```

## [부록] 특정 패키지만 빌드하는 방법

---

```bash
colcon build --symlink-install --packages-select <package_name>
# 또는 cbp <package_name>
```

- 때로는 (대규모 프로젝트의 경우) 모든 패키지를 컴파일하고 싶지 않을 수도 있습니다. 이렇게 하면 시간이 오래 걸립니다. 대신 위 명령어을 사용하여 변경한 패키지만 컴파일할 수 있습니다.
