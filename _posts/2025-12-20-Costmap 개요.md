# Costmap

• 로봇이 이동할 수 있는 영역과 이동할 수 없는 영역을 나타내는 2차원 그리드 맵
• 각 셀은 특정 비용(Cost) 값을 가지며, 이 비용 값은 로봇이 해당 셀을 통과하는 데 얼마나 어려운지를 나타냄

## Global Costmap vs Local Costmap
![](/assets/img/ros2nav2/img/Screenshot%20from%202025-12-20%2011-55-32.png)
- Global Costmap
    - 사전에 우리가 알고 있는 지도를 기반으로 해서 장애물 영역에 대해 Inflated Obstacle이 생김
- Local Costmap
    - 지도 값이랑 상관없이, **내가 실제 움직일 수 있는 범위 내에서** 센서 정보를 토대로 Inflated Obstacle이 생김


    |  | Global Costmap | Local Costmap |
    | --- | --- | --- |
    | 목적 | 로봇의 전체적인 경로 계획을 위해 사용 | 로봇의 실시간 장애물 회피 및 단기 경로 계획을 위해 사용 |
    | 범위 | 주로 정적인 장애물(고정된 벽, 건물 등)을 반영 | 로봇의 현재 위치 주변의 동적인 장애물(움직이는 사람, 다른 로봇 등)을 반영 |
    | 업데이트 주기 | 전체 맵을 기반으로 하기 때문에 업데이트 빈도가 낮음 | 상대적으로 작은 맵을 사용하여 빠른 업데이트 |


# Costmap Layer

• Static Layer

    • 사전에 정의된 맵 파일을 로드하여 환경의 고정된 장애물 정보를 costmap에 반영

• Obastacle Layer

    • 로봇의 센서를 사용하여 동적인 장애물을 감지하고 costmap에 반영

• Inflation Layer

    • 장애물 주변에 안전 영역을 설정하여, 로봇이 장애물과 안전 거리를 유지

• Voxel Layer

    • 3차원 공간에서 장애물을 표현하기 위해 사용
