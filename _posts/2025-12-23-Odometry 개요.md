# Odometry

---

- 로봇이나 차량이 자신의 시작 위치로부터 현재 위치까지 얼마나 이동했는지 추적하는 데 사용
- 주로 로봇의 위치 추정 및 탐색 시스템에서 사용되며, SLAM과 같은 더 복잡한 탐색 알고리즘에서 중요한 초석 역할을 함
- 오도메트리는 센서의 누적 오차와 환경적 요인에 의해 error가 증가할 수 있기 때문에, 보다 정확한 위치 추정을 위해 SLAM과 같은 기술과 함께 사용되거나, 추가적인 센서 정보로 보정되는 경우가 많음
    - 사용 가능한 센서에 따라 로봇의 주행 거리를 계산하는 방법에는 여러 가지가 있음
        - Wheel Odometry
        - LiDAR Odometry
        - Visual Odometry
        - Wheel Inertial Odometry
        - LiDAR Inertial Odometry
        - Visual Inertial Odometry
        - GNSS Odometry
        - …
- 상용화된 대부분의 모바일 로봇에서는 **엔코더(encorder), IMU**와 같은 센서를 융합하여 시간에 따른 로봇의 위치 및 방향(포즈)을 추정
    - 이 추정 결과는 SLAM 및 Navigation에서 모두 중요하게 사용

## 왜 Odometry가 자율주행에 있어 중요한 정보인가?

- **Mapping**
    - 로봇이 환경을 탐색하며 주변 구조의 지도를 생성할 때, 오도메트리는 "언제, 어디서" 센서 데이터를 취득했는지 알려주는 기준점 역할을 합니다. 센서가 관측한 특징점(feature)들을 올바른 위치에 배치하려면 로봇의 이동 궤적 정보가 필수적입니다. 오도메트리 없이는 센서 데이터를 공간상에 정렬할 수 없어 일관된 지도 생성이 불가능합니다.
- **Localization**
    - 이미 구축된 지도 내에서 로봇의 현재 위치를 추정하는 과정입니다. 오도메트리는 이전 위치로부터의 상대적 이동량을 제공하여 위치 추정의 초기값(prior)을 제공합니다. 특히 GPS가 불가능한 실내나 터널 등에서 오도메트리는 연속적인 위치 추정을 가능하게 하는 핵심 정보원입니다. 다만 오도메트리는 시간이 지나면서 누적 오차가 발생하므로, 카메라나 LiDAR 같은 외부 센서와 융합(sensor fusion)하여 오차를 보정합니다.
- **Navigation**
    - 목적지까지의 경로 계획 및 추종 과정에서 오도메트리는 실시간 위치 및 속도 정보를 제공합니다. 로봇이 계획된 경로를 얼마나 잘 따라가고 있는지 모니터링하고, 동적 장애물 회피나 재계획이 필요할 때 현재 상태를 정확히 파악하는 데 사용됩니다. 경로 추종 성능은 오도메트리의 정확도에 직접적으로 영향을 받습니다.
- **Feedback Control**
    - 제어 시스템이 목표 궤적과 실제 궤적 간의 오차를 계산하려면 현재 상태(위치, 속도, 방향)를 알아야 합니다. 오도메트리는 이러한 상태 정보를 제공하여 PID 제어나 Model Predictive Control (MPC) 같은 제어 알고리즘이 적절한 제어 입력(steering, throttle)을 계산할 수 있게 합니다. 고정밀 오도메트리는 부드럽고 안정적인 주행을 가능하게 합니다.
- 오도메트리는 자율주행 시스템의 "뼈대"와 같습니다. 정확도는 제한적이지만, 다른 센서들과 융합되어 전체 시스템의 성능을 결정하는 기반 정보를 제공합니다.


# **모바일 로봇에서 2D LiDAR가 주로 사용되는 이유**

---

## **Wheel Odometry의 단점**

1. **휠 슬립 (Wheel Slip)**
    - Wheel Odometry는 바퀴가 지면과 완벽하게 접지되어 미끄러짐 없이 회전한다는 가정에 기반합니다. 하지만 실제 환경에서는 다음과 같은 상황에서 이 가정이 무너집니다.
        - 미끄러운 표면: 진흙, 눈, 얼음, 젖은 노면
        - 불규칙한 지형: 자갈, 모래, 두꺼운 카펫
        - 급가속/급감속/급회전 시
    - 휠 슬립이 발생하면 바퀴는 회전하지만 실제 이동 거리는 더 짧아져, 측정값과 실제값 사이에 오차가 발생합니다. 이는 시간이 지남에 따라 누적됩니다.
2. **누적 오차 (Drift)**
    - Wheel Odometry는 **적분 기반 Dead Reckoning** 방식으로 작동하기 때문에, 작은 측정 오차도 시간과 이동 거리에 따라 계속 누적됩니다.
        - 0.1%의 거리 측정 오차가 있다면, 100m 이동 시 10cm, 1km 이동 시 1m의 오차가 발생
        - 방향 오차는 더 빠르게 누적되어 로봇의 heading이 실제와 크게 달라질 수 있음
    - 이러한 누적 오차는 외부 센서(LiDAR, 카메라 등)를 통한 보정 없이는 계속 증가합니다
3. **바퀴 변형 및 마모**
    - 바퀴와 구동계의 물리적 변화가 측정 정확도에 영향을 줍니다.
        - **타이어 마모**: 사용에 따라 바퀴 직경이 점차 감소
        - **타이어 압력 변화**: 온도나 공기압 변화로 바퀴 직경이 변함
        - **펑크 또는 손상**: 바퀴 변형 시 회전당 이동 거리가 달라짐
    - 이러한 변화는 사전 정의된 바퀴 직경 값을 의미없게 만들며, 시스템은 이를 자동으로 감지하거나 보상하기 어렵습니다.

## **그럼 2D LiDAR 단독으로 2D LiDAR Odometry를 사용하면 되지 않나요?**

### 2D LiDAR Odometry 단독 사용의 한계

1. 특징이 부족한 환경 (Feature-poor Environments)
    - 2D LiDAR는 **scan matching** 기법을 통해 연속된 스캔 간의 기하학적 특징을 매칭하여 이동량을 추정합니다. 하지만 다음과 같은 환경에서는 특징 매칭이 어렵습니다.
        - **긴 복도**: 평행한 벽면만 존재하여 전후방 구별 불가
        - **빈 공간**: 넓은 광장이나 야외 주차장처럼 반사 특징이 희박한 경우
        - **반복적 구조**: 동일한 패턴이 반복되는 환경 (기둥들, 창문들)
    - 이런 환경에서는 scan matching이 여러 개의 가능한 해(multiple hypotheses)를 가지거나, 최적화가 **local minima**에 빠져 잘못된 매칭 결과를 낳을 수 있습니다.
2. 회전 운동 시 정확도 저하 및 누적 오차 (Drift)
    - 오랜 시간 동안 누적되는 작은 오차들이 큰 위치 오차로 이어질 수 있습니다.
    - 특히 회전 운동을 할 때 LiDAR 데이터만으로는 정확한 각도를 측정하기 어렵고, 이로 인해 위치 추정이 점차 부정확해질 수 있습니다.
3. 동적 환경에서의 문제
    - 움직이는 물체나 주변 변화가 심한 환경은 데이터의 노이즈로 작용할 수 있습니다. 이는 로봇이 정적 환경과 동적 환경을 구분하지 못하게 하여 위치 추정 오류를 일으킬 수 있습니다.
    - 동적 객체를 **outlier로 제거하는 필터링**이 없으면, 이들이 매칭에 포함되어 위치 추정을 왜곡시킵니다. 특히 동적 객체가 많은 환경일수록 문제가 심각합니다.

> 위 문제점들을 해결하기 위해 일반적으로 엔코더, IMU, 또는 다른 센서들과의 센서 융합을 통해 오도메트리를 구현합니다.

# Extended Kalman Filter (EKF)

---

## EKF란?

- **비선형 시스템**에 대한 상태 추정을 위해 Kalman Filter를 확장한 알고리즘
- 여러 센서 데이터를 통합하여 로봇의 위치와 자세를 높은 정밀도로 추정하는 데 사용
- Kalman Filter vs EKF
    - **Kalman Filter**: 선형 시스템에만 적용 가능
    - **EKF**: 비선형 시스템을 선형화(linearization)하여 Kalman Filter 적용
- 로봇의 운동 모델(motion model)과 센서 모델(sensor model)은 대부분 비선형이므로, 자율주행 시스템에서는 EKF를 많이 사용합니다.
